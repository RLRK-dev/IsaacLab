# HVJB：部品群から筐体内外の作業を見る

11群・92写真特徴を、完成品の中の位置と、部品群だけの表示で比較する。
初期表示は「B：筐体外の組立」。補機ヒューズ5個と板を、主ヒューズ・被覆と分けた。

- `index.html`：部品群と2つの向きを切り替える。JavaScript無効時もB図と全群一覧を読める。
- `all_groups.html`：11枚の見開き図を縦に並べる。
- `figures/`：44画像。相対位置・形状は保存モデルから変更していない。
- `sheets/`：11枚の説明図。左右は別の拡大率。
- `group_review.json`：既存群・20仕事・各特徴の候補対応と未確定事項。
- `render_receipt.json`：表示対象・カメラ・各特徴の可視画素・入力同一性。

部品群だけを表示した図は、分解手順・中間工程の形状・そのまま一体搬送できる状態を示さない。
写真のモデルと2025年の公式組立映像の製造版の一致は未確認。
筐体外の可搬下板の正確な形状、抵抗等の写真で見えない対象、配線の未見区間は追加していない。
主ヒューズP22/被覆P08、各線の両端、共締め積層、隠れた固定点は未確定として残す。

補機ヒューズ板側の端末を箱外で締結する工程と、反対端を搭載後に接続する工程を区別する。
部品群への対応候補は物理施工の確定ではなく、正式な物理妥当性判定を含まない。

動画は既存v05の1本を参照し、この追加資料で別種類の動画を生成しない。
