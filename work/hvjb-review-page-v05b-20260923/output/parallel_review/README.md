## 表示の意味

- 補助が必要なセルの8組合せは**独立した仮定例**。時系列、発生頻度、タクトではない。
- A+B、A+B+Cで同じ補助腕への割当が重なる。重複のない例も、実機の並行動作成立を意味しない。
- Cで前の一式、A/Bで次の一式を準備する説明図。1つの箱へ3ST分の腕を集める図ではない。
- 保持中の腕を切り替えるボタンではない。支持引継ぎ・開放・退避・必要な交換と移動を先に置く。
- C補助を筐体搭載終了だけで空き扱いにしない。既存のD31〜D50の継続予約を描く。
- 機種、実機台数、手先交換方式、支持面、検出、実時間、物理妥当性は今回選定しない。
