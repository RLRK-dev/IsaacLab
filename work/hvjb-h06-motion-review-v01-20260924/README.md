# H06・パレット受け渡しを全体動画へつなぐための図示

既存の H06_FC02 比較モデルと保存済みの載置／取出し各5姿勢を使う。
新しい把持面、クランプ、ピン、センサ、制御条件は設計しない。
目的は、全体動画の簡略ハンドでは見えない四隅の受けとピン逃げ、
支持を引き継いでから開放する順序を同じ工程動画内で確認できるようにすること。

- 入力は2026-09-20のGLBと受け渡し観察JSON。コピー時と読戻し時にSHAを照合する。
- 載置はP01の56メッシュ、取出しは保存製品92特徴・465メッシュを表示する。
- 指66メッシュ、治具12メッシュを再利用する。紫色はクランプの配置予約外形。
- 18 mmのクランプ外形移動、片側22 mmの指開き、12/60 mmの上昇は既存比較姿勢。
  採用ストロークや実機の寸法、公差・検出閾値ではない。
- 5姿勢間を直線移動で補間する。各10秒は説明用の表示時間で、実タクトではない。
- ピン部の拡大では周囲を非表示にする。位置決め穴の嵌合を示す画面ではない。
- 蓋・外部ハーネスは追加しない。取出し画面は内部付き保存モデルであり、
  未確定の完成品仕様を補ったモデルではない。
- 全体動画側の模式座標へ実寸比較モデルを無理に拡大縮小して組み込まない。
  全体の模式動作と局所の比較姿勢は、同一の実機軌道ではないことを表示する。

受け渡しの確認項目は既存案の手順表現であり、センサ測定値や開放許可の実装ではない。
把持力、荷重、公差、ピンへの導入、クランプ機構、ロボット／コンベアとの干渉、
物理妥当性を判定する資料ではない。v06、以前のモデル・動画・納品は保存する。

この作業では工程PNGを作り、全体動画の次版へ取り込む。
単独の追加MP4、中間raw MP4、全景動画は生成しない。

初回プレビューは同一メッシュを2個のOpenGLコンテキストで使用して停止した。
描画器を1個にして画面サイズを切り替える修正で再試行する。
元の形状・姿勢・カメラを変える修正ではない。失敗したpreview01は納品しない。
