# PNGの補助観察

2026-09-24。`output/process/manifest.json` に記録した300枚の工程PNGを読戻し、
`audit/contacts/loading.png` と `pickup.png` の各9枚・計18時点を画像表示で確認した。
最終構成と同じプレビューでは、載置後の指開放、手の上昇、内部付き筐体の接近・上昇も拡大表示した。

- 載置側は空のP01、取出し側は内部付き保存モデルとして表示されている。
- 取出し側にはオレンジの外側ヘッダー、内部の接触器・ヒューズ・配線表示が残っている。
- ピン部分の別画面では、指の開きとピンが残る位置を同じカメラで追える。
- 最終版では指の上昇後もピン下端と指上端が画面内に収まり、説明欄への重なりは見られなかった。
- 各段階の見出しと説明欄は画像内に表示されている。

初回の描画コンテキスト共有エラーはPNG完成前に停止。
preview02/03では拡大画面の固定範囲が不足したため、全端点の外形を含む固定画角に変更した。
この変更はカメラ・画面配置だけで、FC02の形状・比較姿勢は変更していない。
失敗・調整途中のプレビューは納品しない。

画像から実際の接触圧・把持安定性・ピン嵌合・全機構の干渉を判定していない。
