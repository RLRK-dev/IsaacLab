## 今回の前進

既存D71の「検査設備」を、公開された機能検査治具の用途へ対応づけた。
作業分担は、ワーク支持、試験接続、設備による検査、試験接続の解除・退避に分けて図示した。
これは既存の設備中心の比較案を具体化したもので、Ampereの自動接続機構を再現したものではない。

パレット・治具が必要な支持を担当できる場合、ロボットは接続前後に限定して兼務を比較できる。
腕による支持が必要な場合は検査中も腕の占有を残す。現時点で兼務成立や腕数削減を確定していない。
ケース用H06、内部ハウジング用H05、外側ヘッダー用H05と試験プラグ用の保持は別用途として扱う。
試験用プラグの保持面・ラッチ操作を、既存の指へ無条件に割り当てていない。

- 自動接続・解除機構、必要軸、保持反力、検査待ち中のC主腕兼務。
- S02の内製／購入境界、S09の遮蔽された工具先端、S13の実配線の両端。
- 主ヒューズP22・被覆P08の取付工程。補機ヒューズ板側の外組みと一括しない。

現在の5腕役割・20仕事・12元工程、20枠共用ストッカとXYZ、1段往復パレットを維持する。
