# C工程：手先の切替方式を比較する

`index.html`を開く。3方式と6場面を選ぶと、本体・爪・置台に残る部品の違いを確認できる。
比較画像と交換中の支持の画像はフォルダ直下。これは方式選定前の図で、実寸CADや軌道ではない。

## 確認する違い

1. 兼用爪：交換部品を持たない候補。ただし板用とユニット用の輪郭・開閉範囲の両立は未確認。
2. 爪だけ自動交換：同じ本体を使い、専用爪へ替える。本体の開閉範囲は交換しても同じ。
3. 手先一式の自動交換：板保持用と搬送用の本体から分ける。交換部・配管配線接続・置台が必要。

3方式の採否と具体型式は未選定。H07とユニット用H06の例であり、筐体用H06の流用ではない。
図のH07/H06は用途名。実際の取付互換・爪寸法・ストローク・荷重値を割り当てていない。
手先を2種例示したことは、C全作業を2種で賄えるという判断でもない。

交換中もF-Cで本体を支持し、必要な自由端案内を続ける。板間接合の荷重受容、F-Cの支持面、
複数の自由端を個別に案内する方法は未確定のまま。締付工具は据置側を維持する。
交換・確認・往復をC主腕の占有から除かない。動画v05eの持ち替え5説明秒は実交換時間ではない。

## 根拠と記録

既存D30/D31/D40と手先計画を継承。自動爪交換はSCHUNK BSWS-R、手先一式交換と置台は
