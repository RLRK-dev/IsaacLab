# HVJB：筐体内外の組立区分

2026-09-21。ユーザーの「筐体内で組み付けるものと、筐体外で組み付けるものを明確にして」に対応。
既存の外組み工程、採用済みユニット化手順、後続の搬送指定を、場所と部品・接続箇所で整理した。
新しい実物接続や締結仕様を選定する変更ではない。

## 現在の区分

| 作業場所 | 対象・作業 | 担当 |
| --- | --- | --- |
| 筐体外・準備 | 線材の切断・被覆除去・圧着、内側ハウジングへの端子挿入。入荷済み範囲は未確定 | PREP |
| 筐体外・下板 | 接触器・リレー・抵抗等を下板へ組付け、下板側で完結する配線を接続 | A |
| 筐体外・補機ヒューズ板 | 板側部品の組付け、板側配線端末の締結 | B |
| 筐体外・ユニット合流 | 下板とヒューズ板の位置合わせ、保持中の板間ねじ固定、自由端退避 | C前半 |
| 外から内への搭載 | 二つのユニットをまとめて筐体へ入れ、支持を引き継ぐ | C |
| 搭載後・筐体内 | ユニットの筐体固定工程枠、バスバー・丸端子・共締め部材の残接続 | C |
| 搭載後・側壁をまたぐ | 内側ハウジングと線の開口通過、外側ヘッダーの設置・ねじ固定、内側端末の組付け | C |
| 搭載後・位置の個別照合が残る | LV/HVILの残接続、主接続口・LV口の細部 | C |
| 筐体上面・検査 | シール・蓋、必要検査。詳細な順序・条件は未確定 | 後工程 |

**補機ヒューズ板側の配線締結は筐体外で行う。** 同じ配線でも、板側端末をBで締結し、
残る反対端を搭載後のCで接続する場合がある。「ヒューズの配線」と一括して全端を箱内作業にしない。
ヒューズ本体の保持方式と端末ねじ締結は別事項で、全ヒューズ本体が直接ねじ固定されるとはしていない。

**主ヒューズP22と黒い被覆P08の取付工程は未確定。** 補機ヒューズ5個の外組みと同一扱いにしない。
既存台帳はB/C候補を残している。支持関係・導体の共締め・取付順を確認するまで自動で振り分けない。

Cはすべて箱内作業ではない。ユニット合流は搭載前の箱外、ヘッダー固定は搭載後の側壁外側から行う。
図の「内側」「側壁」2枠は場所の分類であり、同時実行の指定ではない。
O00-O80は既存工程整理IDで、ラインのOP010/OP020等とは別。OP020のヘッダー作業はO50へ1回対応する。
