## ハンド配置の比較入力

前回の後端保持帯3.1 mm、分割押し面、指の輪郭をそのまま再利用した。
元CADの頂点・面を、保存製品の各口に剛体登録する。最大残差は
`3.841705620288849e-09 m`。縮尺変更、製品メッシュの変形・削減はない。

- 本体：保存済みDH PGE-5-26比較外形。公称寸法55×26×95 mm（ブレーキなし）。
- 爪取付基準：製品座標Z=90 mm、支持部の上下範囲44 mm。
- 支持部幅2 mm、奥行4.4 mm、取付座14×14×3 mm。
- 図示爪間隔6.75 mm。各4 mm開くと14.75 mm。

本体と爪は公称の箱形状で、完全なメーカーCADではない。今回の支持部・取付座も
比較形状で、穴・ねじ・ピン、電気配線、ロボット側取付部は含めない。
許容指長・モーメント・荷重・剛性の成立は未確認。
既存のケーブル保持用40 mm後退・15度姿勢や外側ヘッダー用指先は変更していない。

## 幾何計算と検証の範囲

前回の凸区画への三角形切出しを再利用した。
各凸区画の並進掃引は、始終点の頂点を合わせた凸包で表す。
今回の純並進では全中間位置を含み、端点だけを調べた結果ではない。
本体、爪、取付座、支持部、指先を全て含め、広域AABB判定の後に表面を切り出す。

厳密な内部を見るための1 nm内縮は境界接触の数値除外であり、許容めり込み量ではない。
既存関数の結果内には汎用説明 `inside/on closed trial-tip volumes` が残るが、
本スクリプトでは比較名ごとの並進包絡に対して内縮した面切出しを実行している。
片方の立体が他方の内部に完全包含される問題はこの表面検査だけでは除外できない。
保存製品は完成時の表示配置であり、実際の組立途中状態を保証しない。

解析値による切出し3例（0.5 / 0.125 / 0.0）を再照合した。
加えて、端点では見つからず移動途中だけで交差する既知形状を照合し、
解析面積0.18 m²と一致した。これは補助計算の確認で、物理検証ではない。

PDFの文字がページ内に収まる検査に加え、Popplerで全3ページを描画して確認した。
初回の3ページ目で説明文が重なったため位置を直し、最終版を再確認した。
