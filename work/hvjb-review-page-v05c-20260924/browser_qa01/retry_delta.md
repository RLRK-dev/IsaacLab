# 初回UI検査からの変更

2026-09-24。初回は4章への移動、仕事D50からの移動、部品P16の検索、手先図からの
直接リンク、430 px幅での横はみ出し検査を終えた後、requestfailedが空というassertで停止した。
6件とも同じMP4の `net::ERR_ABORTED` で、ページJavaScriptの例外ではなかった。
検査ログと旧検査スクリプト、7枚の画像をこのディレクトリに保持する。

確認した具体的な変更点：

1. 新設したクイックリンクはクリック処理とhashchangeの両方でseekしていた。
   既定のリンク動作を止め、URL履歴の更新と1回のseekにまとめる。
2. 検査は移動後のreadyState=4、seeking=false、指定currentTime、video.errorなしを確認する。
   同じ動画のmediaリクエストで `ERR_ABORTED` のものだけを移動・遷移時の中断として別記し、
   それ以外の失敗は引き続きassertする。生のイベント一覧も残す。
3. 初回フォルダを保ち、新規のbrowser_qa02へ確認結果を出す。

MP4や幾何、動作データ、実機の受入条件を変更する修正ではない。
