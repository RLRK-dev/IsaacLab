# C工程：受け台と搬送爪の接触域を比較する

2026-09-27。v05e確認後のユーザー「ok」を受けた続き。
図で構成を確認してから細部・動作を詰める指示と、部品輪郭に沿う指を比較する指示に基づく。

## 今回の差分

従来資料はF-CとH06系搬送手先の役割を示す記号だった。
今回は、既存H06系の対向2爪・前後4接触域を起点に、受け台の支持域と爪の接近域を分ける
配置の比較図を加える。側面輪郭のみ／側面輪郭と下受けの2案を、受け上・把持・搬送・着座・
開放検討の5場面で並べる。図中の接触域・中央の受け域・下受けは今回の比較記号であり、
製品CAD、実接触位置、支持数、採用寸法、成立判定ではない。

下受けを描いただけで開放できるとは扱わず、筐体内の受け高さ、板下の空間、側壁までの
隙間、指の開放と抜取り経路を残す。側面案も摩擦把持の性能を確定しない。
板間固定の荷重受容は従来の工程上の仮定で、実接合部は未確定。
H07から搬送手先への切替方式と全自由端の担当対応も未確定のまま。
