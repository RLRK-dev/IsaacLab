## 今回加えたもの

- F-Cの支持域と、搬送爪が側縁へ接近する領域を分けた平面図。
- 受け上、把持、搬送、着座、開放検討の5場面の比較図。

- Ampere公式映像の24秒・146秒を元記録のSHAと照合し、無変更で添付。

図の形、接触点、中央支持域の大きさは比較用の記号。製品CADや採用された治具寸法ではない。
下板は現在のモデルに独立して存在せず、筐体P01を代用していない。
既存のH06系2爪・4接触域の方針を引き継ぐが、筐体用爪をユニット用へ兼用すると決めてはいない。
H07から搬送手先への交換・兼用方式、板間固定、全自由端の個別保持も未確定。

## 根拠と限界

`audit/inputs.json`に入力パス・SHA、参考URL、従来成果物の照合数を記録。
SCHUNK公式FGRは個別輪郭・段付き形状が提供される一般例だけに用いた。
公式コンフィギュレータは検索インデックスを読んだが、直接openはcache missだった。
メーカーの型式、ストローク、荷重、力、安全係数は採用していない。

2025年映像と2022年写真モデルの同一版対応、実物の把持許容面は未確認。
v05eのbank・動画・動作、v06原本を変更していない。物理的成立の正式判定は行っていない。

## 作成手順

`build_review.py`で原資料を照合して組み立て、`qa_review.mjs`で全5場面・4画面幅の表示と
参照画像を確認し、2枚の比較画像を書き出す。`deliver_review.py`で新しいDownloadsフォルダに
コピーし、全ファイルのSHAとv05eの既存ファイルを再照合する。
各出力先が既存なら停止する。元ファイルの上書きや自動的な削除は行わない。

初回は別ディレクトリにある同名の入力JSONを一つの保存先へコピーしようとして停止した。
元の相対ディレクトリを残すよう修正した。`RETRY_DELTA.md`に理由と差分を記録している。
作業名の日付は着手日の2026-09-27。納品・確認の実時刻は各監査JSONに記録する。
