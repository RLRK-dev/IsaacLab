# HVJB 写真モデルの92項目 — 位置図と単体図

既存92項目と20仕事の対応を確認するための表示資料。
保存済みの頂点・面を使い、部品・配線・締結点を追加、修正、結合しない。
完全な実物BOMや不可視配線の復元を意味しない。

- 位置図：92項目・465メッシュの完成状態をすべて含め、選択した特徴を青く表示。
- 単体図：その特徴に属する保存メッシュだけを表示。単体ごとに拡大率は異なる。
- 遮蔽：完成状態の同じ視点で選択色が見えるピクセルを別の識別描画で計数。
  この値は描画上の観測であり、物理干渉・施工可否の判定ではない。
- 元の特徴ID、工程の検討先、未確定点は前段の台帳をそのまま継承する。

`render_atlas.py`は既存の製品読込とpyrender描画部品を再利用する。
保存形状の配列ハッシュを生成前後に照合し、図・出典SHAを`output/atlas.json`へ記録する。
出力先がある場合は停止する。`--feature_ids`で表示確認用の小集合を指定できる。

事前検索：`HVJB 92項目 単体表示 部品対応`。判定結果は監査記録を参照。
設計採用・採寸値の実物保証・把持力・締結品質の判定は行わない。
