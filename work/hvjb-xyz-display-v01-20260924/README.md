# 共用XYZの筐体取出し表示の補修

v05bの保存済み模式動画では、供給時の持上げ区間に限り、手先基準点と筐体基準点の
Z差が0.155から0.14へ変化していた。完成品を戻す区間は0.14一定だった。
これは実物寸法ではなく、無次元の表示座標である。

既存の運搬中の差0.14へそろえるため、元の補間時計4.0〜5.6に限定し、
既存のsmoothstep曲線で手先のZを補正する。最初の接近を連続的につなぎ、
4.6〜5.6の持上げで筐体との相対位置を一定にする。

- 対象は infeed のpalm、左右finger、carrier、Z軸表示の5列のZ平行移動のみ。
- 製品、パレット、他アーム、カメラ、時刻、指の開閉量、回転は元データと同一。
- 旧NPZとv06は保存し、結果は新しいNPZへ出力する。
- 20区画の共用ストッカ、同じXYZによる取出し・収納、1段往復コンベアは維持する。
- 元データで相対位置一定のチェックが成立しないことと、補修後の保存読戻しを確認する。
  数値計算の1e-12は製造・把持・干渉の許容値ではない。
- ロボット型式、関節軌道、制御、把持性能を新たに決定する変更ではない。

事前の `H06 XYZ 表示ずれ` prior-art guard は blocker 0。
