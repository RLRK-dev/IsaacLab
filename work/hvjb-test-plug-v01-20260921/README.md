## 確認できたこと

- 前面補機5口は、既存対応表のP16（A/D/E）とP17（D/F）へ対応する。
  用途ラベルとI01～I05の対応は、公開写真・図面・モデルの並びを組み合わせた推定を継承。
  I01～I05は内側ハウジングの既存IDであり、外側試験プラグのIDではない。
- TE図面2103177 Rev B3は、指操作型、工具操作型、それぞれのCPA有無を区別している。
  比較用に指操作型4-2103177-x／5-2103177-xを列挙した。注文品番・試験ハーネスの採用ではない。
- 公式の解除例は、最初のラッチ操作、中間位置までの引戻し、次のラッチ操作、抜去に分かれる。
  中間位置の約4.5 mmではHVILは開いてもHV端子は接触中。線を引いて抜く操作は指定されていない。
  英文と日本語の該当図をそれぞれ読んだ。

## 比較として具体化した部分

既存腕が位置合わせと挿抜を行う案と、固定の案内・挿抜機構に分担する案を図にした。
プラグ本体の位置・向きを決める保持部と、ロックの操作部を別機能として扱う。
これはユーザーの形状に沿う保持方針を試験プラグへ適用する概念で、メーカーのロボット治具ではない。
模式図の接触面・配置は寸法や成立性を示さない。図面・現物と照合した機構の新規実装は行っていない。

既存H05の指先を流用できる証拠は未取得。ラッチ操作用の機能が必要でも、追加腕が必要とは決まらない。
保持指の数、ロック操作子の数、駆動軸の数、腕の数を分けて扱う。
検査中に腕を空けられるのは、本体・線・接続維持の支持を設備へ引き継げる場合に限る。

## 未確定の範囲

- 実際に試験へ接続する口の集合、全試験項目、条件・合否値・時間、蓋との順序。
- 主電力2口P14/P15、低圧12極P18の相手側型式と固有の着脱方法。
- プラグ一式の採用品番、線・端子・HVIL構成、CPAの採否・操作方法。
- 図面上のキー一致は候補抽出であり、完全な嵌合適合・試験ハーネスBOMの確定ではない。
- CPA固有の操作は今回読んだ一般の二段ラッチ手順から補完しない。
- ラッチの検知、把持面、力、全ストローク、許容ずれ、操作子数、交換方法、繰返し寿命。
- 約4.5 mmは公式資料の中間位置の目安。合否値、公差、全抜去量、自動化指令値ではない。
- HVIL開は無電圧を意味しない。試験停止・抜去許可は設備の未確定仕様として残す。
- 5口同時挿抜の採用、新しい腕数・軸数、物理妥当性判定は行わない。

OP020の外側ヘッダー設置・ねじ固定は維持。試験プラグの着脱はD71の別用途である。
主ヒューズP22・被覆P08の組付け工程、内部の隠れた締結点と物理配線も引き続き未確定。
