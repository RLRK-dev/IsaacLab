# 板用ハンドの模式表示の追加整理

2026-09-24。前段の3か所の相対位置修正は数値確認を通過したが、同一カメラの拡大図
`../hvjb-hold-display-v01-20260924/comparisons/B_next_0825.png` で、板用の前側の指が
模式部品の白い箱に重なることを観測した。元の先行板の姿勢を再利用しただけでは残る問題である。
前段のbank・9比較図・検証JSONは保存し、未納品のまま次の補助確認へ進む。

今回は実物の把持設計を選定せず、既存の板・搭載部品・指の単純な箱形状から、
白い部品より上の表示領域を読取り、指先の表示位置をそろえる。
図解上の空き領域中央へ指先下端を置く。これは説明図の配置規則であり、
許容把持面・十分な接触面積・製作寸法・把持力・安全離隔の決定ではない。

Bの先行板と次の板、Cの受取り側を同じ高さへ合わせる。
Cの受取り時の手先方向も、既存の板側縁用90度へ接近中にそろえる。
板・部品・工具・線・パレット・カメラの保存値は変更しない。
箱外組立・箱内搭載・3ST・S5_ABの仕事と役割はそのまま維持する。

前段とは具体的に異なる観測（手と部品の相対一定では発見できない、模式形状同士の重なり）に対処する。
先行する支持面が未確定であることは解消しない。AABB重なりの読取も正式な物理妥当性判定にはしない。
