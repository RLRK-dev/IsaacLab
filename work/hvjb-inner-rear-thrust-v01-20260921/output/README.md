## 今回の差分と観測

前回の比較Bの保持帯（source Z = -42.2〜-39.1 mm、帯幅3.1 mm）を残す。
支持部だけを後方のZ = -43.5 mmまで延長し、CAD最小Z面へ当てる段を付ける。
前回の干渉したつば押し案を採用し直すものではない。

押し面の半径方向の内端は前回外周プロファイルから-0.5 mm、外端は+1.0 mm。
支持部は+1.0〜+3.0 mm、パッドは+0.1〜+1.0 mm。これらは今回の比較入力であり、
加工寸法やユーザーが選定した仕様ではない。部品のCAD頂点は変更しない。
0.1 mmの表示逃げを残しているため、図示状態を接触・把持成立と呼ばない。

5口の保存CADに対する観測は共通：

- 後端の平面三角形272枚、合計約20.3733 mm²。
- 追加段の投影と平面の重なりは片側約2.74104 mm²、左右合計約5.48209 mm²。
- 後端の0.0005 mm内側で抽出した2穴断面と、段の投影との重なりは0 mm²。
- 元の内側ハウジング表面が指先の厳密な内部へ入る切出し面は0枚。
  接触境界を除く1 nmは数値計算用で、許容めり込みではない。
- 閉じた位置の外側ヘッダー表面切出しは0枚。

開放比較では各指を外側へ0〜2 mm、その後に軸方向へ0〜8 mm後退させる。
この単調な2並進の全中間点は各端点を含むAABB内に収まる。
その包絡と保存ヘッダー全体は軸方向でP16側0.450068 mm、P17側0.500069 mm離れる。
表示壁の内端とは5.0 mm離れる。この限定された部材の間隔を、全体の非干渉、
組付け成立、公差込みの余裕、実機軌道成立へ拡張しない。

穴断面を塞がないことと、実電線や端子を避けることは別問題。
実電線の曲がり・出口からの占有領域、ハンド本体・取付具・周辺内部品は未評価。
また、細い樹脂縁の許容荷重、必要挿入力、樹脂変形、指を開いた後の残留保持が未確定。
図の「保持を確認→開放→後退」は依存関係の説明で、確認方式や受入しきい値の指定ではない。
