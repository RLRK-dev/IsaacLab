## 反映した内容

- 下板側Aと補機ヒューズ板Bの筐体外組立、Cの箱外結合、一体搭載、搭載後の内部・側壁作業を分離。
- 旧v02に含まれた未採用のA/B共用補助のC同行を外し、C主担当と専用補助の役割を表示。
- 単純な形状モデルの中で、板の厚さ方向の把持とユニット両側の把持を区別。
- Cの持ち替え時は台の支持を残す。搭載後の主担当は上昇・退避し、案内役の占有を残す。
- ヘッダーの工具表示を差込口からフランジ周辺へ移した。実際の全ねじ位置・軸選定ではない。
- 残接続の代表場面では、工具退避・指開放後の両腕上昇を同じ時間窓にした。
- 1段コンベア、一定のパレット高さ、同じ経路の往復、20枠共用と同じ枠への収納を継承。

## 図示の範囲

腕・手先・筐体・内部品は旧v02の簡略モデルが基礎。写真92特徴の精密再現、
最新の指先詳細メッシュを全工程へ適用したモデル、採用ロボットの関節軌道ではない。
線は配線群の記号であり、本数・両端・全保持方法を表さない。
特にC専用補助1腕だけで全自由端を扱えることを、この動画では確認していない。

H06の内部ユニット用への転用、F-Cの支持形状、手先交換方式、実物の板間固定点・荷重受容は未確定。
H05内側と外側の役割を分けるが、全口の施工順、内側ロックと全フランジ締結の詳細順は未設定。
主ヒューズP22・被覆P08の組付け工程、個々のLV/HVIL端末、隠れた工具作業点を補っていない。
後工程完了を仮定した物流の場面へ切り替えるが、その前の接続・検査が成立したとの判定ではない。
把持力、滑り、反力、実機干渉、締結品質、物理妥当性を判定する動画ではない。

## 再利用と記録

`legacy_model.py` は旧v02表示コードの読取り用コピーから、旧ラベルと実行入口を除いたもの。
カメラ分岐の別関数化、明示return、import・書式を整理した。
旧コードとの23時点・304動的ノードのworld行列とカメラの一致を記録した。
v03差分は `render_process.py` にまとめ、元のv02、native、v06は変更していない。

表示プリミティブは既存 `render_ur15_line.py` の関数を再利用する。
同ファイルの旧サイト動画、旧ライン配置・タクトを設計根拠にはしていない。
エンコードは既存 `encode_process_review_video.py` と `collect_saved_geometry_review.py` を再利用。
工程PNGと保存姿勢の対応、入力SHA、全編デコードを照合する。
動画生成と補助的な表示確認は、VaultProtocol V12の独立した物理判定と分離する。
未確定表示の上に役割ラベルが重なるS09/S13は、`finalize_labels.py` でラベルを整理する。
同じ保存行列・カメラを使い、前後PNG・スクリプト・入力のSHAと対応を残す。

`inputs/original_sources.json` に読んだ原本9件のSHAを固定。
`data/concept_v03.npz` は表示用行列、`data/concept_v03.json` は工程・入力・フレーム対応。
大きい動画・NPZ・全PNGはローカル証拠として保存し、Gitでは生成コード・工程表・監査を保存する。
Downloadsにも動画と行列・工程表・確認記録をまとめる。

制作途中の修正：初回は端末種別dumbによりラッパーのtabs処理が停止したため、
TERM=xtermを指定した（Python未起動）。画像確認後、工具方向・腕ラベル・搭載後の退避表示を修正した。
これらは説明表示の変更であり、測定値や物理条件の変更ではない。
