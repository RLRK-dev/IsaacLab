2026-09-20。1枚の比較図をPDFとPNGで収録。新しい実物形状や動作を作成したものではありません。

前回判明した丸溝の軸滑り・軸回りの残課題に対し、黒被覆の完成外形で候補を分けます。
Aは円弧受けと交換式の弾性接触層。Bは被覆表面に実在する非円形の輪郭を使う条件付き候補です。
六角形は図解例です。Klaukeの資料には六角圧着・インデント等の複数の方式があり、
Ampereの線種・端子・圧着方式をこの図から指定するものではありません。

被覆表面の凹凸が小さい・柔らかい・内部が動く場合、外形一致だけで回り止めは成立しません。
非円形断面でも長手方向の形状拘束は別です。荷重を受けられる実在の肩が確認できた場合だけ、
その黒被覆側への端当てを比較します。架空の肩、取手、追加カバーを製品に作っていません。

現行資料はKlauke 6R6の未圧着CADと説明用黒被覆であり、Ampere完成配線の把持寸法には使えません。
前後パッドが両方当たること、被覆への圧力と端子内部の滑り、開放経路、実工具の空間は未確認です。
