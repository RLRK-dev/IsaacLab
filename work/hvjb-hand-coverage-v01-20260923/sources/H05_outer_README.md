## 反映した内容

- 全8種類に、形状に沿う基準面、押付け側、荷重を受ける面、向き基準、開放する方向を対応づけました。基準側と押付け側を分ける方針です。全面を剛体で無理に一致させる仕様にはしません。
- 部品をフィンガの中で意図的に滑らせて位置合わせする工程は想定しません。挿入時は、把持位置を保ったまま手先全体で位置や傾きを合わせます。手先の柔軟機構・センサ型式は選定していません。
- 把持完了、持上げ、搬送・姿勢変更、組付け・締結、支持引継ぎの全区間を対象にします。最後は受け側へ支持を渡してから指を開きます。把持幅・物体検出だけを「滑りなし」の証拠にはしません。
- 元の20仕事を `position_retention_plan.json` にそのまま残し、それぞれに全8種類の保持方針を対応づけました。S5_AB、XYZ、1段往復パレット、筐体と完成品の20枠共用を継承しています。
- H04は端子側の黒被覆＋根元被覆、40 mm後退、15度の既定値を維持します。金属端子把持や撤去済みの上押さえは復活させません。

## 今回、実際に作成した3D形状

H05外側の3口P16（TE 2103340-1）、2口P17（TE 2103346-2）について、公開CADから比較用の指先を作りました。`models/` の2つのGLBに元のハンド機構と対象部品を含みます。元のnative、メッシュ、動作バンクは変更していません。

- 側面：フランジ端の丸い輪郭に沿う受け。公称高さ37 mm、厚さ方向3.5 mmの帯は**今回の比較値**です。
- 前面：組付け方向の荷重を受ける小さな当て。筐体側の密着面・シール側へ爪を差し込む構造にはしていません。
- 既存の片側5×10 mmの公称対向面に対し、今回の輪郭帯の公称対向面は約133.46 mm²／片側です。**実荷重下の接触面積ではなく、保持力が2.67倍になったという意味でもありません。**
- 0.1 mmはモデル比較の幾何逃げであり、採用加工公差や実際の把持すき間ではありません。実際の閉じ量、パッド圧縮、予圧を解いたモデルではありません。
- 2口・3口はそれぞれのCADから輪郭を抽出しました。同じ爪を無条件で共用できるという決定にはしていません。内側端末は別の外形・接触面照合が必要です。
- 取付けの旧参照ハードウェアを保持しています。ねじ止め詳細、強度、部品メーカーによる把持面の許可は未確定です。

その他7種類は今回、位置・向き保持の**構成図と要求の更新**までです。各実部品に適合した詳細3Dフィンガ、寸法公差、材質、力、連続アーム動作は未作成です。H06の筐体と一体ユニット、H07のカバーと板は同じ実部品ではなく、接触面を別々に照合します。

## 観測と限界

`contour_observations.json` に入力SHA、輪郭点、公称面積、開放時の補助観測、描画条件を記録しています。

- 保護対象の入力SHAを実行前後と梱包時に照合。比較GLBは保存後に読み戻して19メッシュ／モデルを確認しました。
- P16の28保存姿勢、P17の29保存姿勢に、新しい側面受けを重ねています。既存の指が開くときの上昇も含む変換を使用し、単純な水平移動に置き換えていません。
- 側面受けの内向き頂点を、CADの9断面から得た外形包絡へ照合しました。観測された最小側方距離はP16約0.099730 mm、P17約0.099815 mmです。0.1 mmの比較逃げを含む値であり、接触圧、挟み込み、全固体の干渉、連続軌道の判定ではありません。照合帯域内に含めた点の数をJSONに記録しています。
- 追加した爪表面に対するねじ軸の投影半径は最小約6.6135 mmです。追加爪だけの観測で、全ハンド・工具一式のクリアランスではありません。採用工具が未定のため、工具が必ず通るとは結論していません。
- 形状で受けられる方向にも、実部品の許容面・強度確認が必要です。反対向きの引張や滑らかな円筒の軸回転など、摩擦保持が残る方向は明示しています。ケーブルは被覆自体と端子の間の滑りも対象です。
- 全8種類で「位置と向きを保つ」はユーザー指定の要件です。許容並進・回転、把持力、材質、加速度、接触圧の合否値は新しく発明していません。正式な物理妥当性はVaultProtocol V12の独立レビュー経路によります。
