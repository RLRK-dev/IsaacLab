# H06 筐体の四隅に合わせるフィンガ比較

`pdf/` の2ページをご確認ください。青が指先の受け、青緑が接触パッドです。
`models/` のGLBは空筐体／部品取付後の比較形状、`pages/` は資料のページ画像です。

2本の指に各2か所の受けを設け、筐体の実在する外側取付フランジを下面・上面・側面・端面で包む案です。
中央の固定受けへ着座した後、指を左右へ開き、上方へ退避する比較姿勢を作りました。
ストッカとパレットにはフランジ下と左右の逃げが必要です。20区画共用、XYZ、1段往復コンベアを維持します。
常設の上押さえではなく、上面パッドも搬送フィンガの一部です。

## 資料の位置づけ

- H06_FC01は今回の比較案。製作仕様、採用する駆動部、荷重保持の合否を確定していません。
- 公開図面の筐体外形は292.10 × 160.00 × 92.29 mmで、コネクタの突出分は別です。
- 保存P01は写真推定の形状。フランジ厚さ6 mmを含む詳細は実測・公差付きCADではありません。
- 比較用の0.2 mmの隙間、片側22 mmの開き、60 mm退避、受け高さは製作寸法・許容ずれ・実機軌道ではありません。
- 完成品と共用する狙いですが、部品取付後の表示は蓋なしの公開写真モデルです。
  蓋、実際の完成状態の外形、荷重条件は残ります。
- 92項目の465メッシュを保持。内部ユニットを筐体P01と同じ対象とは扱っていません。
- 製品を形状に合わせるための突起や取っ手は追加していません。製品モデル、T050既定値、ライン動画は変更していません。
- AABBの重なり候補が無いことは補助的な幾何観測。把持力・締結品質・物理妥当性は別途検証が必要です。

詳細と入力SHAは `H06_contact_observations.json` にあります。
実際のフランジ形状／許容荷重、質量・重心、接触材・押付け量・局所追従、駆動部と指根元荷重、置き場と隣区画を詰めてから動作へ反映します。
