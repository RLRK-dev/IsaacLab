# H06とコンベアパレット上の筐体位置決め

`pdf/` の3ページが配置、指の逃げ、載せる／取り出す受け渡しの比較案です。

- 3点支持：筐体下面。A1/A2は低いフランジ保持クランプの直下で受ける。
- 丸ピン＋ダイヤピン：既存の対角取付穴を使用する比較。穴公差・基準関係は未公表。
- フランジ保持：H06が四隅で持つ範囲を避けたC1/C2。実際のクランプ型式・外形・荷重は未選定。
- 180度反転対策：4穴だけでは区別できないため、前面の向きを確認する役割が必要。
- パレットとSTの位置決めは別に必要。固定高さで停止・横位置決め・保持する構成。パレットを持ち上げない。
- 移載中はH06の保持を継続し、着座とパレット側保持を確認してから開く。取出しでは逆に引き継ぐ。
- XYZ全体または手全体で位置を合わせる。クランプした筐体を指内で意図的に滑らせない。
- 搬送中の保持、供給停止時の挙動、着座／クランプ検出は型式を選んで確認する。検出閾値は未設定。
- 着座が未確認ならCで無理に押し込まない。次の保持が未確認なら、それまでの保持側を開放しない。
- H06退避後にパレットのST固定を解除して搬送。取出しはCの退避確認後、両ピンを上へ抜けてから横移動。

## H06の追加変更

前回H06_FC01は下受け板が取付穴の下を横切るため、位置決めピンを下から通す経路がありません。
H06_FC02の比較では上下の受け板をU字にし、筐体側へ逃げを開けています。パッドだけの溝では足りません。
前回モデルと納品、元の製品モデルは変更していません。

## 3Dと観測の範囲

GLBは2本です。reference_envelopesは指とパレット局所治具のみ。handoff_populatedは保存製品92部品／465メッシュも表示。
内部付きの保存製品は蓋なしで、完成品の実物寸法・外部ハーネスをすべて確定したものではありません。
2本の橙の円筒は公称穴径4.90 mmに基づく比較用包絡。製造するピン径やダイヤ断面を採用したものではありません。
3点支持・ピン台座・クランプ配置予約を含みますが、完全なクランプ機構・筐体の穴・ST・ローラーは評価対象外です。
元の写真モデルのリング表示を貫通穴として扱っていません。
48姿勢のAABB比較とGLB読戻しは補助的な観測。全機構の干渉、精度、摩擦、反力、保持成立の判定ではありません。
紫のクランプ外形は配置予約。選定メーカーの製品寸法・作動を表すものではありません。
往復8区間について、各部の相対並進から掃引AABBを計算。指対治具、指対保存製品、C予約外形対保存製品を照合。
回転を含まず、区間の途中位置も含む包絡の比較です。筐体対ピン／支持面は穴嵌合や実接触の評価にならないため含めていません。
開放時のCつま先外形の18 mm移動、片側22 mmの指開き、12／60 mmの上昇は比較姿勢であり、採用ストロークではありません。
12 mm上昇姿勢では参照ピン先端4.8 mmとの差は7.2 mmですが、実機の抜去余裕・合否基準を定めた値ではありません。
最小距離は表示用隙間を含む公称外形の観測で、公差・たわみ・異物を含めた余裕を保証しません。
図の保持役割、着座確認、Cロック確認は必要な手順の表現で、実センサや制御を実装・測定した結果ではありません。

## 公開値と未確定事項

Ampere V1.1 p.2：取付穴φ4.90、中心間276.35 × 133.35 mm。
既存モデルの装飾リング中心ではなく公開図面の穴パターンを基にしています。
位置決め精度を決める穴径・位置公差、ピンはめ合い、支持面、質量・重心、フランジ強度は未確定です。
XYZ直交軸だけでは筐体の回転ずれを補正できません。ストッカでの向き・姿勢再現と、手全体でずれを逃がす方法を要検討。
公称中心が一致する直線経路は、ずれた実物がピンへ導入できることを示しません。ピン入口の案内形状も未選定です。
指内で筐体を滑らせることでこの問題を解いたことにはしません。手首側の微小な逃げ・必要な追加機構は未採用です。
Carr Laneは原理の参照のみで、参照ページの6 mm以上のピンを4.90 mm穴に採用していません。
今回の静的比較からST機構・ローラー・隣接物まで含む成立へ拡張しません。
