# H05外側ヘッダーの保持・開放を動画で確認する

P16（TE 2103340-1・3口）とP17（TE 2103346-2・2口）について、
2026-09-20の輪郭フィンガ比較GLBと、既存のヘッダー固定後の保存開放姿勢を再利用する。
元の製品、指形状、ロボット動作バンク、機種選定は変更しない。

- GLB各19メッシュを保持し、元の追加爪が元パッドに従う関係を再利用する。
- P16は28姿勢、P17は29姿勢。新たな関節補間やIKを計算せず、保存姿勢を順送りする。
- 左は保持・開放・上方退避の局所表示、右は同じ爪の把持位置の接触形状を固定表示する。
- 説明用に同じPNGを繰り返してスロー表示する。表示秒数は実機のタクトではない。
- ヘッダーは保存開放窓の全姿勢で位置不変。これは固定後を表す図示で、
  締結完了・把持力・接触圧を測定した結果ではない。
- 筐体・工具は局所表示では非表示。全体の20仕事やOP020のねじ固定工程を省略する変更ではない。
- 0.1 mmの表示逃げ、輪郭帯、前側受けは既存の比較値。加工公差・予圧・許容把持面は未確定。
- 内側ハウジングH05、H04黒被覆の40 mm後退／15度姿勢とは別の用途。

今回作るのは工程PNGとその同一性・変換の読戻し記録。
最終的には全体工程と同じ1本の `*_split_process_*_review.mp4` にまとめる。
