# HVJB：ヒューズ対応候補と配線追跡

2026-09-21。前回 `4cc1cd9368` の補機5口対応を受け、ヒューズ実体と各口の対応を調べた。
公開写真の可視範囲、追加4フレーム、保存台帳と公開回路を照合した。
**新しく確定した実配線は0件。定格と一対一対応の仮定の下で、4通りの候補を列挙した。**

## 条件付きで分かったこと

次の三つを仮定する。実物の同一個体・同一版で成立することは未確認。

1. 写真の5ヒューズが、V1.1の補機5系統と一対一に対応する。
2. 写真の実装定格と公開回路の定格が一致する。
3. 前回の外観表示と保存モデルI01〜I05の位置対応が対象の構成へ適用できる。

| 写真ID | 台帳に保存された読取値 | 上の仮定で残る口 |
| --- | --- | --- |
| P05 | 未読 | I02 AC / I04 Charger |
| P06 | 30 A | I02 AC / I04 Charger |
| P19 | 20 A | I01 Heater 1 / I03 Heater 2 |
| P20 | 20 A | I01 Heater 1 / I03 Heater 2 |
| P21 | 10 A | I05 DC-DC |

30 A群の入替え2通りと20 A群の入替え2通りで4通りになる。
P05の30 Aは仮定からの帰結であり、帯色や不鮮明な印字の読取りではない。
`observed_current_a` を埋めず、元のnullを保持する。
P21→I05も定格による条件付き対応であり、線を追って確認した接続ではない。
系列文字・採用品番・接点・締結積層・経路は補完しない。

JSONではこの分析を `conditional_analysis` に分離し、前回のポート表をそのまま複製する。
全口の `physical_fuse_photo_id`、各接点の `photo_wire_id` / `electrical_node` はnullのまま。
既存27可視線区間と続き候補もそのまま保存する。W04→WI52、W05→WI42を確定線にしない。
I03のWI31/WI32を再作成せず、必要接点20個、写真92特徴、17機能、13回路群、LV12極を保持する。

## 調べた画像と限界

- [公式記事][article]から公開写真DSC02860-1、DSC02864、DSC02878を確認。
  保存済みの[DSC02861-1][fuse]も読んだ。ヒューズの定格読取は2026-09-15の訂正済み台帳を継承する。
- [公式組立映像][video]の62 / 70 / 78 / 86秒を既存のffmpeg抽出方法で無加工出力。
  62秒は板側の端点が手で隠れる。86秒は手・身体・線の交差が個別追跡を遮る。
  70秒は複数製品の挿入写真、78秒は蓋付きの挿入写真で、実作業の連続経路ではない。
- 2025年の手書き番号を、2022年写真のP/I/W番号へ移していない。
  自動字幕は時間探索にだけ用いた。写真や字幕の近さを電気的な接続としない。
- 新しい原フレームは62秒と86秒を同梱。70秒・78秒は重複する製品写真場面のため記録のみ。
  全4枚のハッシュ、抽出元と引数は `output/extraction_record.json` にある。
  元動画と全4原フレームは記録されたローカルパスに保存。工程動画は生成していない。
