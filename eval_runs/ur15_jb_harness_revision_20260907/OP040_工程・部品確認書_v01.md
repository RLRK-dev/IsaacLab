## 2. 接続案の前提

図面・部品表が未提示のため、以下は**動画用の製品構成案**。現実の特定車種の回路を復元したものではない。
採用すると入荷部品の定義と後続ST配置にも差分が生じるので、確認済みv06のモデルへ直ちに書き込まない。

実製品の参考として、EatonのEV用PDUは駆動系・補機への分配に加え、ヒューズ、接触器、プリチャージなどを扱い、端子・バスバーを統合している。
この機能区分を参考にする。[Eaton公式PDU](https://www.eaton.com/us/en-us/catalog/emobility/power-distribution-unit.html)

**構成案は、保護・分配をまとめた入荷済みサブアセンブリD04を明示し、J2/J3/J4へ2本ずつ、計6本の端末加工済みケーブルを取り付ける方式。**
D04という識別子、6本という本数、端末の割当は本検討で提案したもので、メーカー資料の仕様ではない。
機能ブロックを入荷済みとする場合、その内部組立は本ラインの前工程として明記する。
ヒューズ・接触器等がない現形状を電気的に完成した製品と表示しない。

## 3. 接続案を採用する場合の工程構成案

両腕のフィンガで曲げる工程と、アーム常設の締付ユニットで締める工程を維持するため、
**OP040A＝配線設置、OP040B＝締結の2STに分ける案**を第一候補とする。
既存OP040から1ST増える提案であり、まだ追加・移設していない。
OP040Aは既存の＋X側、Bは−X側とし、下流も含めて千鳥順序と必要なライン長を見直す必要がある。

| 小工程 | OP040A：両腕フィンガ | OP040B：アーム常設締付ユニット |
| --- | --- | --- |
| ワーク搬入前 | 次に使う線材の供給・方向を準備 | 各工具を専用供給ユニットから事前装填 |
| ワーク受入 | 同一パレットを停止し、上昇させず位置決め | 配線UID・着座状態を引き継ぎ、停止位置決め |
| 取得 | 両腕で同時に1本の両端寄りの被覆をクランプ | 空工具は次の締結前に直ちに補充 |
| 搬送・曲げ | 固定した線長で両腕を協調させ、既設2本を避けて配索 | 左右工具を独立接続座へ同時に位置合わせ |
| 設置・締結 | 端末を接続座へ置き、離す前に支持を確保 | 工具干渉がなければ両端を同時締結。接続部の回り止めを確認 |
| 退避 | 両指を解放後、同時に鉛直退避 | 両工具を同時に軸方向へ抜き、補充へ戻る |
| 次線・搬出 | 6本をUIDで追跡。未締結線が運ばれる支持条件を確認 | 締結部品の製品移管を記録し、次工程へ搬出 |

支持を確保する構造は、端末座・回り止め・次工程の恒久クリップとの対応で具体化する。
以前撤去した2つの青いケーブル押さえを代用として復活させない。
供給は「1本ずつ直線で10本並列」の既存方式を再利用候補にするが、6種類の混載・左右方向・補充単位を確定する必要がある。
端末形状・長さが異なる場合は、同じ10本を6回使える在庫と誤表示しない。

## 4. 寸法と仕様を確定する順序

| 項目 | 現資料で分かること | 次に確定すること |
| --- | --- | --- |
| J2/J3/J4概略接点 | 2極、23 mmピッチ、Ø8×20 mmの横向きピン | 実際の内部接続座と端末方式。現ピンにリング端子を直接重ねない |
| 既設主配線 | H03-1/2はØ14 mm。端末形状・最終形は今回保存した入力を継承 | 新H04に同じ線径や端子を無条件流用しない |
| 追加H04 | 6本という構成案のみ | 接続点座標、端末型式、線径、各線長、許容曲げ半径、供給方向 |
| 締結 | 常設工具・専用供給器を使用する方針 | ボルト/ナット方式、サイズ、取付座、反力支持。トルク値は作らない |
| D04入荷品 | 保護・分配をまとめる構成案のみ | 回路・外形・取付・T01/T02との独立接続。上流モデルへの変更範囲 |
| 設備構成 | 2STへの分割案 | ST追加を採用するか。下流の位置、供給器・配管・カバー枠との整合 |

まず「J2/J3/J4へ計6本、入荷済みD04を明示、配索と締結を2STに分ける」という構成を確認し、
その後に接続部寸法→線長→供給形状→両腕動作→保存メッシュ確認の順で具体化する。
図面・部品表がある場合は、その構成を優先する。
