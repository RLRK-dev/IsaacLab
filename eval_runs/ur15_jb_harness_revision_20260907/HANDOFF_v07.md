## 4. 背景の要点

### 試算の根拠

作業定義の秒数（`op030_support_motion_v04.py`、`op030_fastener_operations_v04.py`、`op030_motion.py`）と保存 bank のフレーム数から導いた。作業定義合計 250.0 秒に対し A bank 238.8 秒のため、**換算係数 0.955** を一律適用。

**すべて保存アニメーション時間の相対比較であり、実機タクトではない。** 映像用の関節上限 1.2 rad/s（実測最大 0.981）下の値。相対比較は成立するが絶対値は使えない。

### 効いている事実

- **A の 67% はボルト作業**。支持部のハンドリングは 9.4 秒、M4 取得 31.7 秒＋締結 39.2 秒。
- **工程順序は厳密**（支持部設置 → ケーブル設置 → 端子締結）。各 ST の担当は順序付き作業列の連続区間でなければならない。
- **案④で律速が ST2 へ移る**。ST1 60.4 秒 < ST2 63.1 秒。E4（ケーブル落下、復帰最大 63.1 秒）も ST2 で、**律速と最大リスクが重なる**。
- **鏡映変換** `M(y) = diag(−1,−1,1) ＋ Y 方向 2y`。行列式 +1 の 180° 剛体回転で FK が保たれ、自己逆変換。v06 の `delta`（ST2、+1.2）と `baseline`（ST1、−3.4）がこれ。ST3 は +5.8。
- **複製機構 `duplicate_set()` が既存**（`op030_split_layout.py:84`）。`obj.copy()` で mesh 共有、命名は `prefix + "__" + name`、`split_source_name` を刻む。作業3で再利用できる。
