# ヘッダー締付工具のSTEP確認と仕様確認票 v01

2026-09-19。前段の先端図面に続き、公式公開ZIP内のSTEPメタデータを読んだ。

| [SEV 20 / 581145][sev] | 2020-12-09 08:42:15 +01:00 | 1件、581145 | 19件 | 0件 |

両STEPの生成元はAutodesk Inventor 2018、スキーマはCONFIG_CONTROL_DESIGN。
形状名はいずれもVolumenkörper1という汎用名だった。17/19は形状レコードの件数で、
購入部品の点数・可動部数ではない。各製品番号からビットを指す子部品や品番は特定できず、
形状内のビット有無や長さの測定は行っていない。

ZIPにはそれぞれSTEPとEXEが1件ずつ入っている。STEPをメモリ内で読み、EXEは展開・実行していない。
原データのZIP/STEP SHA、単純なエンティティ宣言の型別件数、対象メタデータ全文を
`audit/hvjb_header_tool_cad_metadata_v01_p02.json`に保存した。ヘッダー原文は改行も含め
`references/hvjb_tool_tip_cad_20260919/step_headers/`へそのまま保存し、JSONにパスとSHAを記録した。
この読取はピン留めした2ファイル用で、汎用STEP解析や製造BOMの復元ではない。

2016年の保存SES2001 / SEV2001と、今回の2020年例示STEPは別々に保持した。
部品IDが特定できないまま例示外形を再変換しても、採用ビットの構成情報は増えないため、
この段ではCAD変換・形状変更・動作生成へ進めていない。

## 仕様確認票：回答が必要な4項目

1. **実ねじと受け側**：採用ねじの完全品番・長さ・頭部/座金・駆動穴、受け側の材質、
   着座面・積層・穴底・有効ねじ部を示す図面。
2. **工具とビット**：そのねじに対応する工具・ビット・ノーズの品番。装着突出量、
   係合基準、取付面から締付基準点までを示す構成図またはCAD。
3. **各状態の位置と外形**：供給・接近・締付・復帰、詰まり排出、ビット交換時の
   ノーズ・真空管・爪・ビットの位置と必要空間。
4. **取付と供給**：アダプター・穴配置・軸まわりの向き・継手側・供給ホース。
   座金/フランジを含む実ねじの供給適合を示す資料。

回答欄はJSONでもnullを維持した。一般冊子の送り量、例示図の1〜2 mm、
前段の工具全体0〜100 mm移動を、実ビット長や締付TCPへ読み替えない。
仕様確認票は未送信。実部品構成の指定を受けた時点で、既存14軸へ対応付けられる。

## 実行記録

`scripts/prepare_hvjb_ses2001_cad_v01.py`のZIP/STEP読取と、既存のSHA保全処理を再利用した。
追加処理は指定されたメタデータ宣言の抽出と、既存TE条件・14軸を使った確認票の生成。

確認票の値を変えず、p02のヘッダー参照から復元したモデル記録と確認票を初回JSONと照合する。
