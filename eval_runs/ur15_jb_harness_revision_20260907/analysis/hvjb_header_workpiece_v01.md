# ヘッダー保持手とワーク表面の静止確認 v01

2026-09-20。保存済みH05の14保持姿勢について、現在のp03筐体・ヘッダーとの
表面の位置関係を追加観測した。工具仕様の選定を必要としない範囲の確認である。

**各姿勢で返った11対は、すべて左接触パッドと把持対象ヘッダーの三角形の組だった。**
黒い機構本体・キャリアと、今回対象にしたワーク表面との組は0件だった。
これは保存表面に対するAPIの戻り値で、把持の成否・接触力・貫通深さではない。

## 範囲と座標

- 前段の`audit/hvjb_header_hand_access_v01.json`が記録した14時点をそのまま使用。
  P16はframe 575/605/635/665/695/725/755/785、P17は1135/1165/1195/1225/1255/1285。
  保存motion.npzの行列・フレーム・ヘッダー位置・閉指令とも照合した。軌道は再計算していない。
- 全14手先オブジェクト、51,580三角形を各姿勢に含めた。
  内訳は機構10、キャリア2、パッド2。形状の間引き・縮小やパッドの除外は行っていない。
- 旧保存ワールドからその時点のヘッダー位置を引き、現行表示配置へ平行移動した。
  P16の基準は(-0.052, -0.080, 0.046) m、P17は(0.072, -0.080, 0.046) m。
  Xは正面の右、Yは筐体側、Zは上。これは既存表示モデルの配置で、Ampere加工図の寸法ではない。
- 公式CADの全三角形を材質別の3区分から集め、元CADの面集合と一致することを照合。
  頂点を上記位置へ移した値との最大座標差は、P16で6.306357686e-9 m、
  P17で6.824731821e-9 mだった。1e-7 mの保存数値比較値は既存の開口修正検査から継承。
  手先の旧局所境界との照合には前段の1e-10 mを継承し、受入公差へ読み替えていない。
- ワークはP01の全保存面と、P16/P17の全公式CAD面・全表示ねじを対象とした。
  表示ねじは未採用の仮形状のため別欄にした。隣ヘッダーは設置位置にある参照配置で、
  その時点で実際に取り付いていることや、両ヘッダーの同時施工を仮定しない。

戻り値に現れた手先は`left_left_header_pad`のみ。各姿勢でパッドの7面とヘッダーの3面が
11通りの組として返った。11か所の物理接触という意味ではない。相手側の材質区分と面番号、
全980オブジェクト対の結果は監査JSONに残した。

右パッドの0件から「触れていない」とは結論しない。[Blender BVHTree API][bvh]を
既存の`probe_hvjb_entry_display_v03.py`から再利用し、epsilon=0の表面重なりを観測した。
同一平面・接線接触、縮退面や保存精度の影響は残る。固体包含、離隔量、貫通深さ、
滑り・たわみ・把持荷重・締結反力はこの観測の対象ではない。

腕・カメラ・別の保持手・配線・内部ハウジング・実締付工具は含めていない。
0件をライン全体の干渉解消や実機把持成立とせず、正式判定はV12独立経路へ残す。
今回の記録だけで、指先形状・閉指令・工具配置を変更していない。
