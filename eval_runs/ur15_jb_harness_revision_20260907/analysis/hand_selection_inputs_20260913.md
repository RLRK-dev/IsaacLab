# 工程別ハンド選定：入力資料と検討順

2026-09-13。根拠は今回のユーザー指示、指定されたv0.1/v0.2文書、ローカル生成コード、下記公開資料。
これは比較・確認用の文書。ハンド型式、実機能力、受入数値を確定したものではない。
動画制作とアーム軌道の変更は停止したまま。

## 1. ユーザーが指定した方針

- 公開資料の範囲でAmpere EV HVJB-5-400の回路・主要構成へ合わせる。上流製品も新版で見直し、確認済みv06は保全する。
- 3STに工程を分担し、別々のワークを並行して処理する。
- 単腕で完結する作業は単腕。OP030-A/Bは双腕を必要とする例として明示された。
- 必要なら3腕、3本指、4本指も検討してよい。全工程への採用指示ではない。
- 指先形状・指の本数を先に確定し、その後でアーム動作を検討する。

したがって、対象部品・把持面 → 指数・配置・駆動方式 → 指先と受け面・柔軟性 → 把持位置と開放経路 → 腕数・配置の最終対応 → アーム軌道、の順に整理する。
腕数は並行して候補比較できるが、未定の手先を前提に完成軌道を作らない。

## 3. OP030-BのS字に関する訂正と観測

現在の映像は所定の曲線を描いているが、実物が両端把持でその曲線になることを検証していない。

- `scripts/op030_split_wire.py:112` の `WireBend` は、先に完成経路を読み取る。
- 同ファイルの `sample()` は各区間の向きを直線から完成形へ補間し、区間長を保って中心線を積算する。その中心線から端子姿勢と把持点を作る。
- `scripts/op030_split_wire_motion.py:236` はその形を使い、手の目標姿勢を対応させる。手の力・トルクからケーブル全体の形を求める計算ではない。
- v06の長さ保存・端点一致・FK/幾何照合は、この所定形状に関する補助観測。把持力、被覆圧縮、滑り、曲げ剛性、形の安定性、解放後の戻りを実証しない。

両端把持による形状制御そのものを不可能とはしない。[双腕による弾性線状物の形状制御研究](https://arxiv.org/html/2502.07509v1)は、端点の位置だけでなく接線方向を扱い、弾性モデルと安定性を検討している。論文の物性・重力に関する前提を、今回のHVケーブルへ無条件に適用しない。

**2Fから4Fに増やしても、狙ったS字全体が自動的に定まるわけではない。** G4は手元の30 mm間隔の2組であり、離れたケーブル中間部を別の腕で保持する構成とは異なる。対象の曲げ・ねじれ特性、把持部で伝えられるモーメント、必要な中間支持を区別する。

Bの比較対象には、双腕での端部位置・向きの保持、局所支持を増やした指先、着座面での案内、必要なら第三の独立した支持を含める。方式は未選定。撤去済みの2基のケーブル押さえを復活させた意味ではない。

## 4. 用途別に比較する指先

次は比較候補であり、全工程へ同じ指を装着する指定ではない。

| 作業 | 第一に比較する接触形状 | 位置決め・力の伝達・開放の論点 |
| --- | --- | --- |
| 筐体・蓋の搬送 | 2Fの平面または輪郭パッド、必要な受け面 | 質量・重心と把持可能面。着座後に爪を抜けること |
| Aの部品保持 | 2Fの専用輪郭・ポケット。必要なら3Fの1対2 | 締付け対象を位置決めする面と押さえを分離。工具の進入場所を空ける |
| Bのケーブル保持 | 2Fの丸底溝＋交換パッドと、4Fの対向2組を比較 | 被覆径への適合、滑り、圧力、局所の向き保持、最終配置からの開放 |
| コネクター組付け | 輪郭＋肩・端面受け。2F/3Fを比較 | 挿入力の受け面と横方向・傾きの逃げ。ロック操作と指の退避 |
| ケーブル支持・送り | 滑りを許す案内面と、保持用接触を分離 | 固定把持と送りを同時に要求しない。4Fの片組開放は残り組の保持条件が必要 |
| ボルト・ナット締結 | アーム装着の専用締付工具 | 既存指示どおり、フィンガで締付工具を持たせない |

指先を替える方式は[Robotiqの公式指先仕様](https://assets.robotiq.com/website-assets/support_documents/document/online/2F-85_2F-140_TM_InstructionManual_HTML5_20190503.zip/2F-85_2F-140_TM_InstructionManual_HTML5/Content/6.%20Specifications.htm)を再利用の基準にする。独自指先には寸法・作用力・モーメントの制限があり、標準指先の定格をそのまま転用しない。

[方向別の柔軟性を持つ指の研究](https://arxiv.org/abs/2307.15589)は挿入方向と横方向の剛性を分ける参考、[触覚を使うケーブル操作研究](https://arxiv.org/abs/1910.02860)は保持と滑り案内の参考とする。これらの研究結果は今回のハンドの達成性能ではない。

| 組付け後の開放・退避 | 全開・中間・把持姿勢の形状と、工具・供給受け・カメラとの関係を確認する必要あり |

仕様書中のV01〜V18は提案された試験計画で、未実行。ここで新しい合否数値を追加せず、幾何の確認、物理・実機評価、Rsによる採用判断を区別する。

## 6. 腕数の割当で維持する論点

- Aは保持用ハンド＋常設締付工具、Bは2つの把持域を持つ双腕を比較の出発点にする。Bの曲げ成立は未検証のまま残す。
- Cは現在M6/M14の同時締結。単腕の順次締結は簡素化候補だが、工具対応とタクトが変わる。従来の同時締結指示を黙って削除しない。
- OP020 v11の空トレーは設備返却。古い両腕トレー返却を現在の双腕必須理由にしない。両端コネクターの搬送と準備操作を対象にする。
- 単純な搬送・蓋設置・小部品装着は単腕候補、固定設備で済む検査も比較対象。荷重や把持方式を未確認のまま単腕成立とはしない。
- OP040以降の旧クリップ・押さえ・ラッチとST数はAmpereの採用部品ではない。公開製品構成へ対応させてから割り当てる。
- 3腕は独立した第三の操作・支持が必要な場合の比較候補。3ST並行や指の本数とは別の設計項目。治具や工具交換も含む設備全体の複雑さを比較する。

今回は入力読取り・差分整理・生成コード確認のみ。新規ハンド、物理制御、アーム軌道、シーン、動画は生成していない。
