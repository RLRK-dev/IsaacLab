# 実物参照と把持面の対応 v0.1

2026-09-13。ユーザーが指先3D比較版を「ok 確認した」と回答したことを記録し、
次段としてAmpere EV HVJB-5-400の公開構成と指先の役割を対応付けた。
前回の形状サンプルの閲覧確認を、実部品への適合や製作寸法の確定とは扱わない。

## 1. 今回具体化したこと

**Aの側面輪郭、Bの丸底溝に加え、部品ごとに交換する接触形状を分ける。**
特にBは、被覆を支える部分と、端子の穴・面・ケーブル出口の向きを決める部分を区別する必要がある。
後者は前回の直線ケーブル用GLBには含まれていない。

今回の成果物は写真上の部材位置と、提案する接触面・空ける場所・未確定寸法の対応表。
写真の枠は部材の位置を示すもので、把持してよい領域を製作図として指定したものではない。
型式や機械寸法の不明な欄は、`data/hand_target_contacts_v01.json` で `null` のまま維持する。

## 3. 指の本数と役割

A/Bの2本指を第一比較候補として継続する。部品の種類が7区分あることは、7ST・7腕・7台のハンドを増設する意味ではない。
どの先端を交換式とし、どこで交換するかは、部品の入荷単位と工程順を含めて次に整理する。

B01の丸底溝は被覆を支える。B02は端子の穴中心・端子面・線の出る方向を扱う。
両者を同じ先端へまとめる場合も、どの面を基準にし、どこで配線に逃げを与えるかを別々に定める。
握力を大きくするだけで両方の位置決めが解決したとは扱わない。

G3の1対2は剛体端末の3点位置決め、G4の2対2は保持組を分ける必要がある場合の候補として残る。
追加した指の役割が未定のまま、全体を3本指・4本指へ変更しない。
S字全体の形状は、端末姿勢・線材物性・支持条件を含む別の検討事項。

## 4. 3STと締結工具への引継ぎ

Aを部品の設置・取付締結、Bを柔軟配線と端末の配置、Cを接続部の締結として扱う割付候補を維持する。
これはTHREADの割付で、Ampereの実際の生産工程順が公開された意味ではない。
別ワークを3STで並行処理する方針、Aの保持腕＋常設締付工具、Bの双腕候補を維持する。

剛体バスバーと配線端子が同じ締結点に重なる場合、Aで一度完全に締めてからBで端子を差し込むような工程にはしない。
重なる順序・仮保持・最終締結を対応表へ反映する必要がある。
部品・工具の図面が未確定の段階で、旧モデルのM6/M14などを実物の採用ねじサイズへ移さない。
Cで大小を同時締結する既存要求を変更する判断も、ここではしていない。

## 5. 数値と確認の範囲

- Aサンプルのφ50 mm、輪郭R25.4 mmは検討用の値。
- Bサンプルのφ14 mm、溝R7.2 mm、長手12 mmも検討用の値。
- 外形図の筐体・取付寸法を、写真上の内部部品へ一律に掛けて加工寸法にしない。
- GIGAVACのメーカー資料も照会したが、公開写真の表示だけでは詳細型式を決められない。
  別シリーズの寸法・ねじ・定格をAmpere内蔵品の仕様として採用していない。

prior-art `GIGAVAC / 端末保持 / 把持面` は該当0・blocker0。
ローカルの既存ハンド資産と前回比較票を再利用し、新たな物理機構・接触モデル・腕軌道・動画は作成していない。
この記録は公開資料、保存写真、今回のファイル照合に基づく。正式な物理妥当性判定は含めない。
