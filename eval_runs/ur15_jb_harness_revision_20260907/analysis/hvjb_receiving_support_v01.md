# HVJB C側の受渡し・支持対応 v01

2026-09-16。S5_ABの5腕を維持し、本体と自由端を分けて受け渡す具体的な担当例を描く。
元のD12/D22/D30とユニット化Q1〜Q3を再利用する。A→Bの順序は表示例である。

## Aの受渡し

- 下板本体：A主担当 → A主担当＋Cの受けF-C → F-C。
- A側の自由端：A/B共用補助 → 共用補助＋C専用補助 → C専用補助。
- 渡す側は開放・退避を終え、必要な手先交換と移動をしてから次の把持へ移る。

これはC専用補助がA側を受けられる場合の手順候補。支持面・同時接触域・荷重移行は未確認。
既にC補助が前ワークを案内中の場合は、そのまま受け取れるとはしない。

## C補助がA側を保持中にBを渡す場合

両側に別々の独立案内が必要な条件を置く。本体はB主担当からC主担当へ渡す候補とし、
B側の自由端は共用補助が持ち続ける。この状態の担当は次の通り。

| 対象 | 担当候補 |
| --- | --- |
| A下板本体 | Cの受けF-C |
| Bヒューズ板本体 | C主担当 |
| A側の自由端 | C専用補助 |
| B側の自由端 | A/B共用補助（Bからの受渡し予約を継続） |

**C受渡しにC主担当＋補助2腕の3腕が関わる比較案**。5腕を6腕へ増やす案ではない。
共用補助はBの受渡しを終えるまでA/Bの次の補助把持へ戻れない。補助不要の仕事も含めた
並行処理やタクトへの影響はまだ未計測。Cの補助が空く支持先を仮定して予約を解除しない。

この付き添いは未採用の比較案で、既存の選択は5腕の役割構成まで。
主担当・工具・2つの案内役の到達と全外形を確認する前に、動作へ転用しない。
板間固定後の持ち替え・筐体搭載への延長は本図では確定していない。

## 抜けと重複の表示

同じC補助へ独立2役を割り当てる例と、受け先なしでB側を開放する例を別に表示する。
検査は担当表の重複・空欄を数えるだけで、把持力・変形・落下・実機成立の判定ではない。
「A側」「B側」の2群は実ケーブル2本や一つの手で全端末をつかめるという主張ではない。
手先を複数対象へ使う場合の接触・駆動・独立性は未確定のまま残す。

上押さえ、追加のケーブル保持機構、受入値、走行軸は作らない。Cの受けは既存比較のF-Cで、
その形状を確定したものではない。元20仕事、5腕決定、静止モデル・動画を保持する。
次は受け面、同時接触する把持域、自由端の次支持、共用補助のC側到達を対応する。
