# HVJB 仕事の分解・ロボット割当・集約案 v0.2

2026-09-16。ユーザーの「仕事を分けてロボットを割り当てて、最終的に少数へ集約」を反映。

**まず仕事を漏れなく分けて担当を置き、同時に必要な保持を残しながら、順番に行える仕事を
同じロボットへまとめる。** 工程ごとにロボットを増設することは目標にしない。
工具・単純移載・検査は、据置工具・直交軸・固定設備に任せる範囲を先に比較する。

## 最初の割当

以下は機種選定前の担当案。R-A/B/Cは主担当の枠であり、3台が最終的な最小台数という意味ではない。
X-A/B/Cは追加の独立保持が必要な仕事の枠で、各セルへの増設決定ではない。

| 作業範囲 | 主担当 | 別に必要な役・設備 | 集約する方向 |
| --- | --- | --- | --- |
| OP010 空筐体供給 | 指定済みのXYZ直交 | 20個収納・受け側位置決め | 払出しとの共用は距離・時間を確認して比較 |
| 線材・端末準備 | 準備設備／入荷範囲を対応 | 切断・被覆除去・圧着・端子挿入 | 未決だから工程から削除、とはしない |
| A 下板側外組み | R-A：部品取得・設置・保持・接続・受渡し | 支持治具＋据置工具。両端独立保持の対象だけX-A | 工具専用腕を据置工具へ分担。順次の部品作業はR-Aが兼務 |
| B ヒューズ板側外組み | R-B：部品・線の取得、設置・保持・接続・受渡し | 支持治具＋据置工具。両端保持の対象だけX-B | 片端作業をR-Bへ集約。必要な両端保持は残す |
| C 合流・ユニット化 | R-C：板合わせ・保持、後の搬送把持 | 下板治具＋据置工具、自由端の案内役 | 工具退避後に治具上で持ち替え、同じ主担当が搬送 |
| C 筐体搭載・端末引出し | R-C：ユニットまたはハウジング | 同時に必要な自由端案内X-C、筐体の受け | 二役が同時なら保持役を分ける。案内終了までX-Cを空き扱いにしない |
| C ヘッダー・バスバー・残接続 | R-C：取出し・配置・保持 | 据置工具、必要時X-C。該当箇所の独立2主軸 | 搭載後の順次作業をR-Cへまとめる。OP020の作業を二重実施しない |
| 蓋・シール | R-Cへの順次兼務を比較 | 支持・締付工具 | Cの次ワークを妨げる場合は直交移載等へ分担 |
| 検査 | 固定検査設備＋必要な接近軸 | 必要なら対象の姿勢変更 | 常設ロボットを前提にせず、必要な仕事だけ割当 |
| 完成品払出し | 直交移載を比較 | 筐体保持の専用手先 | R-C／OP010設備の共用と比較。必要軸数は配置に合わせる |
| パレット循環・補給・空容器回収 | 搬送・供給設備を比較 | 残る手扱い・保持役 | ロボットが担当する時間と設備を数え、省略しない |

A/B/Cは、下板側外組み・ヒューズ板側外組み・合流／筐体組込みという現行の合流型比較を使う。
以前の「A機械部品→B主回路→C補機」という直列分担へ戻さない。
各接続の所属が未確定の箇所は、所属・保持相手を特定してから詳細作業を増補する。

## 集約する順序

1. **工具役を分担する**：保持腕＋据置締付工具を優先比較する。保持を途中でやめて
   同じ腕がドライバーへ持ち替える方法では台数を減らさない。
2. **同一セル内で兼務する**：取出し・設置・保持・受渡しを同じ主担当にまとめる。
   Cの板保持と一体搬送は、完成した板間接合と治具の支持を前提に、時間を分けて担当する。
3. **蓋・払出しをまとめる**：組立後の空き時間を利用できるか、独立した直交移載と比較する。
4. **補助役をセル間で共有する**：X-A/B/Cの同時占有が重ならない仕事だけ、同じ補助ロボットへ
   集約する候補にする。保持が続く間は別セルへ貸し出さない。走行軸が必要なら別計上する。
5. **主担当も再比較する**：実作業時間・工具自動動作・支持付き待ち位置が分かった後に、
   R-A/B/Cの共用を検討する。初期担当枠をそのまま最終台数にしない。

保持と工具、両端保持、ユニット保持と自由端案内は、それぞれ同時に必要な区間を持つ。
反対に、治具上で支持を継続できる持ち替えや、終了後の別部品取得は順次兼務の候補になる。
**止まって保持している時間も、そのロボットの占有時間に含める。**

## 集約を判断するための記録

| 記録するもの | 用途 |
| --- | --- |
| 対象・支持相手・自由端の渡し先 | 保持を抜かずにまとめられる作業を見分ける |
| 把持開始から開放・退避までの占有区間 | 同じ腕へ同時に二つの仕事を割り当てることを防ぐ |
| 動作、工具待ち、工具／手先交換、セル間移動 | 兼務による待ち時間と必要な設備を比較する |
| 部品・工具全体の到達と、指の開閉・退避 | 役割だけは共用できても空間的に届かない案を区別する |
| 完成済みユニットの支持付き待ち位置 | A/B/Cが異なるワークを並行処理できるか確認する |
| 多関節腕、直交ロボット、外部軸、主軸、治具、交換装置、補給・回収 | 腕数だけを減らした見かけの集約を避ける |

時間・到達・荷重が未確定なので、現段階では最小台数や削減率、実機タクトを出さない。
工程表の `seconds` は映像の参照時点であり、作業所要時間には使わない。
3STの並行処理を維持する意図は継承し、台数削減で待ちを増やす案はその影響を明示する。

## 対応と保全

`data/hvjb_robot_allocation_v01.json` に20仕事を登録し、既存工程表v03の12作業へ対応した。
これは製造作業を20回と数えたものではない。各部品・各端末・各締結点の詳細展開が残る。
10件の同時役割条件は条件付きの仕事群を含み、常時10仕事を並行させる指定ではない。
既存の92写真特徴・17必須機能・13接続群・LV12極、未確定の物理接続を残す。

参照：工程表v03、支持・受渡し9場面、手先仮仕様H01〜H08、従来のセル割付v01。
新規の機種・機構・制御・受入条件は選定せず、既存の方式とユーザー指示を作業へ対応させる。
実装は割当表とその照合処理で、ロボット動作や設備モデルを変更しない。

OP010 XYZ＋20個、OP020ヘッダー設置・ねじ固定、T050の40 mm／15度、保持中の締結、
両端同時取得・完了後同時退避、該当箇所の大小同時締付、二段パレット循環と作業高さ789 mm、
上押さえを戻さない指定、動画1種類の方針を継承する。物理妥当性の正式判定はV12独立経路による。
