## 2. 鏡映変換の一般形

v06 の `build_op030_stagger_static_v06.py` が使った変換を一般化する。**コンベア中心を挟んで Y = y の ST を左右反転する変換は**

```
M(y) = [[-1,  0, 0, 0  ],
        [ 0, -1, 0, 2y ],
        [ 0,  0, 1, 0  ],
        [ 0,  0, 0, 1  ]]
```

- 行列式 +1 の Z 軸まわり 180° 剛体回転。**鏡映ではないため、腕・関節・指・カメラの形状と FK がそのまま保たれる。** v06 で実証済み。
- 自己逆変換（M(y)∘M(y) = I）。左→右も右→左も同じ行列で済む。
- 点 (x, y) を (−x, 2y − x の Y 成分) へ写す。すなわち **(x, y) → (−x, 2y₀ − y)**。セル基準は中心線上にあるため Y が不変に見えるが、供給器のように中心線から外れた点は Y も動く。

各 ST の Y：ST1 = −1.700、ST2 = +0.600、ST3 = +2.900。ST 間隔 2.300 m。

**M(y) は Z を変えない。** 床面基準が揃っていない部材は、鏡映しても揃わないまま複写される（§7.2）。

## 4. 移設と複製の違い

v06 は roots の parent を新しい EMPTY へ付け替える「**移設**」だった。v07c は「**複製**」であり、次の差分がある。

1. **名前空間**。複製では UID を保てないため、新しい接頭辞を与える。2026-09-11 裁定により `OP030_S1R_*` 形式を採用。
2. **形状データの共有**。`obj.copy()` のみとし、mesh データは複製元と共有する（2026-09-11 裁定）。片側だけ形状を変える必要が生じた時点で `obj.data.copy()` へ切り替える。**ただし §7.2 の補修は複製前に元へ入れる**ため、共有のままで補修が両側へ伝わる。
3. **オブジェクト数**。B の移設対象は roots 104 / moved 420。3 体複製すると **約 1,260 オブジェクトが増える**。現行 9,570 に対して 13% 増。

## 5. 前提作業 — A と C の複製対象集合

> **2026-09-12 追記。** 写像で得た集合には**そのセル自身の供給器が入らない**。実測で A の
> `OP030A_feeder*` 72 個、C の `OP030C_feeder*` 120 個がいずれも **0 個**、B の
> `OP030B_wire_supply*` 91 個のみが全数入っていた。写像は B の名前から始まるため、B に無い
> 装置は原理的に拾えない。**複製集合 = 写像閉包 ＋ そのセルの供給器（接頭辞一致）**とする。
> 搬送・治具は入れない（ラインは共用で、v06 が据え置いた理由もそれである）。

v06 は `analysis/op040_stagger_layout_inventory.json` の `B_candidate_exact_selection`（roots 104 / moved 420 / fixed 76）に依存していた。**A と C について同等の厳密集合がまだ存在しない。**

判定基準は v06 と同じ。

| 複製する | 複製しない |
|---|---|
| ロボット本体、腕、指、オンハンドカメラ | 製品、搬送パレット |
| 供給設備（支持部格子パレット／ケーブル供給／ナット供給器） | 位置決め台、ピン、ストッパ、センサ |
| 制御盤、空圧箱、FRL、ホースと支持 | 共通のカバー枠、外部 LED |
| ロボット架台（`source_0576_m0050_*`）と足・脚 | コンベアのローラー・フレーム |

**セルごとに構成が異なる点に注意する。**

- ケーブル供給台（`OP030B_wire_supply_*`）は**シーンに 1 組のみ**で、B にしかない。§8-7 の「2 組」は新規製作が前提。
- `source_0587`、`OP030_supply_fixed`、`OP030_supply_kit` は A にしか付いていない（`op030_split_layout.py:422`）。
- `OP030_supply_actuator_mount_foot` 系は A と B にあり、**C には無い**。

集合の検証は v06 と同じ三条件（roots の親が moved に含まれない／`children_recursive` の合計が moved と厳密一致／`moved ∩ fixed = ∅`）による。

## 6. 動作の扱い

**供給側は剛体再利用、製品側は再計画。** 製品とパレットは回さないため、鏡映したセルの動作はそのままでは製品上の正しい座へ届かない。

### 6.1 S1R（T02 担当）

再利用できるのは格子パレットからの取得・持上げ・旋回と M4 供給器からのボルト取得。再計画が要るのは T02 の取付座への設置と M4×2 の締結。A の bank 7,165 フレームは `v05_window` で支持部ごとに分離できる。

- S1L = window 1（T01）＋ 引出し・戻し・完了
- S1R = window 2（T02）を M(−1.7) で鏡映し、製品側だけ再計画

### 6.2 S3R（H03-1 の端子締結担当）

再利用できるのはナット装填と工具の搬送高さへの移動。再計画が要るのは端子座への位置合わせ・締付け・80 mm 軸抜き。

**M(2.9) は M6 と M14 の前後関係を入れ替える。** 計測値で確認済み。

| 供給器 | 現在 world XY | 鏡映先 XY |
|---|---|---|
| `OP030C_feeder_M6` | (−0.550, **2.150**) | (+0.550, **3.650**) |
| `OP030C_feeder_M14` | (−0.550, **3.650**) | (+0.550, **2.150**) |

C は進入順序を H03-2 で M14→M6、H03-1 で M6→M14 と変えて工具本体の半回転を省いている。**S3R ではこの位相最適化がそのままでは成立しない。** 再計画時に位相を取り直すか、供給器の配置を鏡映ではなく個別に決める。

### 6.3 S2L（H03-2 の設置担当）

再利用できるのは 10 本並列供給からの両端同時把持・持上げ・旋回曲げ。再計画が要るのは J1 挿入・T 着座・支持移管・180 mm 同時上昇。フェーズ 16 の「次の直線ケーブル供給へ旋回」（6.87 秒）は 2 セル化により不要になる。

**M(0.6) による S2L の足位置は v05 の B と厳密に一致する。** v05 の静的検査を S2L の干渉確認へほぼ流用でき、§9 の作業 3・4 を短縮できる。差分は §7.2 の補修分だけ。

### 6.4 近接区間の扱い

フェーズ 8–14（J1 挿入・T 着座・支持移管解放、16.00 秒）は 23 mm ピッチの座の上で行われるため、両側同時が成立しない可能性がある。**v07c では時間差方式を既定とする。** S2L を先行させ、S2R はその近接区間が明けるまで上空で待つ。ST2 = 80.9 秒。ST1 の 111.7 秒が律速であるため、タクトに影響しない。検証は v07d の前提として別途行う。

### 7.3 補修の要否（結論）

| セル | 供給器・供給台 | 制御盤 下部板 | 制御盤 本体 p00 / p04 |
|---|---|---|---|
| **A** | **足 33 mm 下げ＋脚 33 mm 延長**（×2） | **30→68 mm 延長** | 未処理（全セル共通） |
| **B** | 不要（v06 済） | 不要（v06 済） | 未処理（全セル共通） |
| **C** | 不要（既に接地） | **30→68 mm 延長** | 未処理（全セル共通） |

**C は補修が要る。** 2026-09-11 に「C 側は補修不要」と書いたのは誤りで、撤回する。当時の検査はオブジェクト全体の AABB で床候補を絞っており、制御盤を一度も測っていなかった。

**A の脚の補修後の長さは 667 mm である。** 建造規則（`build_op030_split_v03.py` の `feeder_stand`）は
脚の上面を供給器台の高さで決め、下面を床の上の足に載せる。A の脚は 634 mm で上面 0.648、C の脚は
654 mm で上面 0.668。C は既に足 33 mm 下げ・脚 33 mm 延長を受けて 687 mm になっている。A に同じ
補修を入れれば 634＋33 = **667 mm**、上面は 0.648 のまま動かない。A と C の 20 mm 差は供給器台の
据付高さの差であり、床補修で埋める対象ではない。

補修は **複製前に複製元へ入れる**。形状データを共有する方針（§4-2）のため、元を直せば複製先にも伝わる。手法は `build_op030_stagger_supported_static_v06.py` の `extend_lower` と足の平行移動をそのまま使う。

筐体本体 p00 / p04 の扱いは Rs 裁定事項とする（§10.2）。v07c の範囲を全セルの是正へ広げるか、現状を維持して記録にとどめるか。

## 8. 検証項目

1. **複製集合の厳密性**（§5）。roots / moved / fixed の三条件。
2. **形状の不変**。複製元の world 行列とローカル署名が変化しないこと。
3. **鏡映の精度**。複製先の world 行列が `M(y) @ 元の world` と一致すること（v06 の許容 2×10⁻⁶）。引出しの 0 / 170 / 340 mm 位置でも評価メッシュが一致すること。
4. **接地**。補修後、A の供給器足と A・C の制御盤下部板の gap が 0 になること。複製先 3 体も同様。§7.2 と同じ溶接コンポーネント単位で記録する。
5. **固定側の不変**。製品・パレット・位置決め装置・カバー枠・LED が動いていないこと。
6. **幾何干渉**。6 セル全ての動作対象について、全保存フレームで意図外交差 0。
7. **供給の独立性**。両側のセルが同時に供給へ進入しても干渉しないこと。ST2 のケーブル供給は 2 組とする（2026-09-11 裁定）。現状 1 組しか存在しないため新規製作になる。
8. **空圧の離隔**（§7.1）。
9. **タクト**。保存動作時間と、実機上限へ引き上げた場合の 2 通り。
