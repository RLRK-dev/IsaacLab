# 40 mm後退と根元クランプ v03

ユーザー指定により、本体後退量の初期値を40 mmに設定しました。端子側縁を保持する先端位置を保ち、取付部の内側にもケーブル被覆を左右から挟む丸底パッドを追加しました。安定化を意図した形状案であり、保持力や実機成立を確認したものではありません。

## 初期形状

|項目|今回の設定|
|---|---|
|本体後退量|40 mm（ユーザー指定の初期値）|
|前方の端子保持区間|端子穴中心から後方4〜12 mm、元の輪郭を保持|
|後方の被覆保持区間|後方61〜71 mm、中心66 mm|
|保持区間の中心間距離|58 mm|
|根元パッドの接触長さ|10 mm、比較寸法|
|溝|参考φ14線に沿う左右各90°、元64角断面から片側17点を抽出|
|パッド中央厚さ|約2 mm、比較寸法|
|青い部材の前後寸法／取付中心から前端|70 mm／63 mm|
|駆動|前方と根元は同じ末節に固定。同一の元2F開閉機構|
|材質・硬さ・許容圧縮・把持力|未確定|

根元は灰色スリーブの後端44 mmより後方にあり、オレンジ色の被覆を挟みます。上から押さえる機構は設けていません。閉じ側の形状では根元の面を参考線に合わせています。交換式の軟質パッドを想定しますが、材料・締結構造・交換方法は製作仕様にしていません。

同じ駆動で端子とケーブルを挟むため、端子寸法と被覆径の公差を吸収し、両方に力を配分する設計が残ります。前方の輪郭には元の0.1 mm表示用隙間があり、本モデルは同時接触の力の釣合いを示しません。

## 4保存姿勢の観測

|保存姿勢|左右パッド中央点の距離|被覆に沿う面の標本点から線表面までの最小距離|
|---|---:|---:|
|near|14.000000 mm|0.000000 mm|
|early|14.806785 mm|0.277474 mm|
|open|30.000000 mm|6.488735 mm|
|clear|30.000000 mm|17.874043 mm|

各側99標本点（断面頂点と面の中点×軸方向3位置）を元の線の三角形表面に照合。近接時の最大距離は1.1242293e-17 m。
距離は符号なしです。全表面の最短距離・全開閉軌跡・圧縮・摩擦・安定性の判定ではありません。離隔姿勢は既存の開放姿勢に25 mmの上昇を加えた静止比較です。

## 工具空間

近接時の工具上部帯（接続面から53.8〜188.876976 mm）で、軸から元の黒い本体までの最短水平半径は28.5 mm。φ40比較円筒との半径差は8.5 mmです。下部帯（3.8〜53.8 mm）のφ12比較円筒との半径差は6.369316 mm。根元パッドを追加したモデル全体に対する補助観測です。実ソケット・締付機・ケースを含む離隔ではありません。

## 元モデルとの関係

v02のD30を出発点に、黒い10メッシュを+Y方向へさらに10 mm移動。青いキャリアの後方部分を同量延長し、前方の保持輪郭のworld位置、元関節角度、参照物を維持しました。追加した4メッシュは左右の丸底パッドとその支持部です。

端子側輪郭の保存位置の最大数値差は1.38777878e-17 m。元入力SHAは `5243e62fca4f585a017015ccec2c56a015541fb1160edf758c6cb0ed51f2fb1a`、生成前後で不変。

取付板はv02の14×31×4 mmと2本のM3ねじ位置・中央の位置決め穴を引き継ぎます。根元支持部が穴の内側に重なるため、パッドを外した状態でのねじ工具アクセスと取付順序は製作詳細で確認が必要です。元の黒い末節に新たな穴は開けていません。

## 保存読戻しと表面記録

GLBは22メッシュ、読戻し境界の最大差1.49011611e-09 m。Blenderは4シーン、各22メッシュ。world行列・頂点SHA・面SHA・個数・表示フラグが保存読戻しで一致しました。

|シーン|ハンド対参考物の表面交差組数|キャリア対元部品|左右指先間|根元追加部対取付部|
|---|---:|---:|---:|---:|
|D40_clear|0|2|0|2|
|D40_early|0|2|0|2|
|D40_near|2|2|0|2|
|D40_open|0|2|0|2|

近接姿勢の根元パッドと線の表面一致、および取付部の表面交差を除外せずに記録しています。Blender BVHは浮動小数点の表面判定であり、符号付き体積や包含を判定しません。
キャリアは元v02にゼロ面積面（左3面／右2面）があり、今回も保持しています。新規パッド・支持部は閉じた辺構造でゼロ面積面は0。これは製作用CADの承認ではありません。

## 参照と未確定事項

[Robotiq 2018-11-30公式説明書](https://assets.robotiq.com/website-assets/support_archives/document_en/2F-85_2F-140_Instruction_Manual_PDF_20181130.pdf)の交換指先と力・モーメント制約、および元メッシュに対応する取付図を参照。保存PDFのSHA照合を実施しました。2019 TM版の別の穴配置を混用せず、標準先端の力の値を延長品へ適用していません。公式PDFはリンクとSHAのみを同梱します。

参照端子はKlauke 6R6の圧着前サンプル、線は仮のφ14です。実際のAmpere端子・電線として同定したものではありません。圧着後形状、許容把持面、被覆径、摩擦、圧力分布、曲げ負荷、取付ねじ・剛性は未確定です。保持しながら同じSTで締結する方針を維持し、アーム軌道と動画は停止中です。正式な物理判定はVaultProtocol V12の独立レビュー経路によります。

## 再生成

付属コードはNumPy / SciPy / trimeshとBlenderを使用します。追加の依存は導入していません。新しい空の出力先を指定してください。

```bash
python scripts/build_hand_root_clamp_v03.py --source inputs/hand_mount_interface_meshes_v02.json --config data/hand_root_clamp_v03.json --directory new_output
blender --background --python-exit-code 1 --python scripts/save_hand_root_clamp_v03.py -- --directory new_output
```

IsaacLab作業ツリー内ではPython呼出しを `./isaaclab.sh -p` で実行します。HTMLテンプレートは生成器と同じscriptsディレクトリに置きます。確認書・ブラウザ観測は別途同梱された記録です。
