# HVJB 3STと腕の分担図 v02

2026-09-16。「図解しないとわからない」というユーザー指摘への表示改善。

`data/hvjb_robot_sharing_v01.json`のS4とS5_ABを左右に描いた。
A/Bの外組みからCへ合流する工程と、主担当・共用補助・C専用補助のアイコンを表示する。
補助が必要なSTを切り替えると、対応する破線と同じ補助への要求の重なりを表示する。
初期表示はA+C。A+Bを選ぶと5腕案にも要求の重なりが残る。

- 青：各STの主担当。橙：共用補助。緑：C専用補助。
- 破線：担当する相手。位置・軌道・到達範囲・ロボット機種の指定ではない。
- 部品の記号：作業の種類。実部品形状・部品数・締結場所の描写ではない。
- 4/5腕：主担当3役と必要時の補助役を対応させた比較上の数。機台数や最小台数ではない。
- 元の5分担・20仕事・保持条件・別設備は変更せず、詳細ページ一式を同梱する。
