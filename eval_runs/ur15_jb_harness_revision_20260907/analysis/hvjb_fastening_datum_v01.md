# 締付工具の軸・取付側平面の観測 v01

2026-09-17。前回取得したSTÖGER例示CADの3形式について、工具軸と取付側の平面を
対応付け、形状上に重ねて表示した。観測値・根拠の円筒面・平面の三角形範囲は
`data/hvjb_fastening_datum_v01.json` に保存した。採用工具や締結姿勢の決定ではない。

## 観測した位置関係

座標はメーカーSTEPをSI単位で読み込んだ保存座標系。軸の長手方向原点はメーカーの
保存座標に従うもので、ワークの締結面やロボットTCPに置き換えていない。

| 例示形式 | 軸の方向・通過位置 [m] | 取付側平面 [m] | 軸と平面の距離 [mm] | 同軸円筒面の根拠数 |
|---|---|---|---:|---:|
| SES1601 | Y方向、X=0 / Z=−0.042 | Z=0 | 42 | 71 |
| SEM2001 | X方向、Y=0 / Z=0.058 | Z=0 | 58 | 15 |
| SEV2001 | Z方向、X=0 / Y=0.080 | Y=0 | 80 | 8 |

CADの円筒面定義を読み、図面に対応する軸の候補座標との一致を確認した。
主軸を全オブジェクトの最長辺や円筒面の最多数だけから決めてはいない。
実際にSEMには別の高さに21面の円筒群があり、工具軸の根拠15面より多い。

取付側の平面は全ての元カラーCADメッシュから、対象座標上に3頂点がある三角形を
抽出して記録した。三角形数はSES 128、SEM 16、SEV 482。
平面座標からの最大残差は順に2.10e−16 / 6.73e−19 / 3.31e−16 m。
抽出した三角形の面積は0.00354277 / 0.00520200 / 0.01220552 m²で、
外接長方形の面積ではない。図の実線はその長手方向範囲を示す補助線であり、
線の全長が連続した支持面・接触面であるとは主張しない。

候補座標の照合に1e−9 m、軸方向に1e−10を使う。これはCADのほぼ一致する数値を
識別する計算上の許容差で、必要離隔・加工公差・接触判定・受入条件ではない。
観測JSONには丸め前の座標と面番号、面の範囲、頂点残差も残している。
読取りライブラリが生成するノード名は、実物BOMの部品名ではない。

## メーカー資料との関係

今回追加で読んだ[SES/SEMのメーカー冊子](https://www.stoeger.com/files/stoeger/downloads/Broschueren/SES_1017_END_ENG_web.pdf)
は印刷日10/2017、全4ページ。SHA256は
`7a2a396fb7cdc3b0aee6f51dfc792db4f21e40afc7f07b5a42470254aa9be58a`。
2026年の現行仕様として扱わない。

- p2の断面図・B寸法で、SES1601の42 mmとSEV2001の80 mmを確認できる。
  SEM2001の58 mmは前回取得したその形式の2D図にも記載され、今回のCAD読取りと一致する。
- p3のナット工具表はSEM-V2001という表記。配布CADのSEM2001と仕様・改訂が完全に同一だと
  仮定して、その表のトルク・行程等を選定値にしない。
- p1/p2/p4と[メーカーのheadstroke説明](https://www.stoeger.com/en/headstroke.html)では、
  給材ヘッドの移動とビットの締付移動を区別している。内部の行程により、工具一式を
  毎回同じ量だけ動かす必要はないという構成が説明される。
- SESの送り行程15/30 mmやSEVの約80 mmは冊子の仕様例であり、この保存CADに適用した
  実際の行程ではない。ビットの突出、ワークとの接触点、開閉途中の爪、給材ホースの
  全経路を、保存姿勢から作り足していない。

前回のSES補足説明には取付面全体による支持、少なくとも3本のねじとキープレートが
案内される。しかし取付穴配置・選定ねじ・アダプターを今回確定したわけではない。
先端形状を見られる範囲と、締付中のTCPを定義できる範囲を区別する。

## 解析面の読取りで直した点

`extract_hvjb_fastening_surfaces_v01.py` の最初の実行は、全材質primitiveに
`brep_index` があるという誤った仮定で停止した。2回目に`include_materials=False`を
試したが、材質分割は変わらず、今度は対応のないprimitiveの`cascadio`情報で停止した。
「Falseにすれば材質分割がなくなる」という途中の説明は訂正する。

[cascadio公開ソース](https://github.com/trimesh/cascadio/blob/0e8668de01bb3659c753d49efbe2395e4299e6b7/src/main.cpp)
の説明と保存GLBのJSONを確認した。`include_materials`は追加材質情報の指定であり、
面番号対応を全primitiveへ補う設定ではない。ライブラリのコードや依存関係は変更していない。

最終版は、面番号が実際に提供されるprimitiveだけ解析面を読み、提供されないノードと
三角形数も必ず記録する。完全な解析面対応だとは扱わない。
これは形状を省く処理ではなく、全形状の照合・描画は別途全ノードで行う。
保存済みSESの最初の解析GLBを再利用し、SEM/SEVはこの修正後に初めて解析出力を作った。

| 形式 | 全三角形 | 面番号あり | 面番号なし | 読めた平面 / 円筒面 |
|---|---:|---:|---:|---:|
| SES1601 | 812,736 | 470,376 | 342,360 | 717 / 554 |
| SEM2001 | 1,544,017 | 365,413 | 1,178,604 | 346 / 190 |
| SEV2001 | 885,750 | 179,155 | 706,595 | 468 / 108 |

全三角形位置は3形式とも前回のカラーGLBと一致した。比較は元GLBのfloat32座標のまま、
丸めなし・符号付きゼロのみ正規化した三角形集合の署名で行う。
頂点順、面順、材質ごとの分割順、面の向きは比較に含めないため、トポロジーや
法線方向の同一性・BREP曲面との完全一致まで主張するものではない。
全ノード行列が単位行列であることも確認した。

失敗ログは`audit/hvjb_fastening_surfaces_v01_stdout.txt`と
`audit/hvjb_fastening_surfaces_v01_complete_stdout.txt`に保存。
成功ログは`audit/hvjb_fastening_surfaces_v01_observed_stdout.txt`、対応範囲と署名は
`audit/hvjb_fastening_surfaces_v01.json`。全解析面の生データは
`previews/hvjb_fastening_surfaces_v01_observed/surfaces.json.gz`に残る。
Pythonラッパーの終了コードだけでなく、例外の有無と完了マーカーを確認した。

## 表示と検証

既存の`_tool_parts` / `_add_parts` / `_look_at`を再利用し、元の18 / 34 / 21表面ノードを
全て描画した。間引き、形状修復、部品追加なし。取付側平面への法線が画面内に来る
剛体表示回転を使用し、前回の12度の見栄え用回転はこの図には使わない。
取付面との距離が画面内にそのまま投影されるが、ロボットへの取付姿勢ではない。

全体図は全形状が画角に入ることを確認。先端図は後部が画面外になることを明記する。
PNG6枚を保存して目視確認し、RGBA全画素が一致する可逆WebPを会話図へ格納した。
工具軸・平面・寸法線は、記録した3D座標を描画時の行列と画角で投影する。

`check_hvjb_fastening_datum_v01.mjs`は既存の専用Chrome/CDP確認処理を利用し、
736/320 px・明暗・3形式・2視野の24条件を確認した。
画像SHA、選択状態、距離表示、縦横比、軸・平面・寸法線の投影位置、はみ出し、操作欄の
重複を照合し、JavaScript例外は0件。元PNG6枚と代表3条件の画面を別に見た。
記録は`audit/hvjb_fastening_datum_browser_v01.json`。

## 再現用コマンド

既存レンダーvenvを`VIRTUAL_ENV`へ指定して`isaaclab.sh -p`で実行する。
出力は新規パスに限定し、再実行前にprior-artガードと具体差分を確認する。

```bash
scripts/extract_hvjb_fastening_surfaces_v01.py --converter_path /tmp/ur15-cad-tools \
  --reuse_ses_glb previews/hvjb_fastening_surfaces_v01/ses1601_surfaces.glb \
  --output_directory previews/hvjb_fastening_surfaces_v01_observed

# 描画時はPYOPENGL_PLATFORM=eglを指定する。
scripts/build_hvjb_fastening_datum_v01.py \
  --surface_directory previews/hvjb_fastening_surfaces_v01_observed \
  --output_directory previews/hvjb_fastening_datum_v01 \
  --output_html /home/rlrk/IsaacLab/work/hvjb-fastening-datum-20260917/fastening-axis-mount.html
```

既存出力がある状態でそのまま再実行するためのコマンドではない。
会話図のプレビューを作った後、ブラウザ確認スクリプトへプレビュー、観測JSON、
新しい確認出力ディレクトリの順で渡す。
