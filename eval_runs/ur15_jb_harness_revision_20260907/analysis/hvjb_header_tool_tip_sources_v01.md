# ヘッダー締付工具の先端・供給条件の公開資料追補 v01

2026-09-19。前段の外形比較に続き、実際の締付位置を決めるための資料を確認した。

**2020年付SES 20 / SEV 20の図面から、先端・供給・交換時の条件を追加した。
ビット品番、装着突出量、取付面からの締付TCPは、この資料では確定していない。**
前段のSES2001 / SEV2001保存CADと同一の構成であるとの確認も取れていない。

## 配置で区別するもの

- SES 20の1〜2 mmは可変の例示間隔。採用ビットの長さ・ねじ頭への係合量ではなく、
  SEV 20や既存CADに共通の停止位置にもしていない。
- SES 20の詰まり復帰注記は、ねじを排出できるよう締付と反対方向へ離れることと、
  ねじ長より数mm長いヘッド行程を説明する。25 / 50 mmをビット行程へ転記しない。
- SES 20は先端爪の開きを示すが、開き角・最大幅の数値はない。両図にビット交換用の
  傾斜姿勢と空間確保の注記があり、保存CADの一姿勢だけで代用できない。
- 供給継手は約240度の向き調整を記載。連続回転する機構や運転中の軌道とは読まない。
  空気継手・ボタン・センサーの左右配置も案件の構成入力として残る。

両図の供給ホース表は、内径1.5〜2.7 / 3〜4 / 4.3〜7.5 / 8〜9.5 / 10〜13 /
14〜16 mmに対し、最小曲げ半径95 / 100 / 110 / 150 / 200 / 300 mmを記載する。
これはねじ供給ホース用であり、HVJBの高電圧ケーブルや未確定の56 mm配線には転用しない。
頭径+1 mmの表見出しから、座金付きねじの供給適合や採用ホースを決めてもいない。

取付面には平面度0.05 mmの記号と、M6取付穴を全て使う注記がある。穴数は可変であり、
本案件のアダプター、実穴配置、取付ねじの締付条件は別途必要になる。

## 次に渡す入力

前段の[外形比較](hvjb_header_tool_envelope_v01.md)は14軸に対応する保存形状の比較として保持する。
0〜100 mmの操作値は工具全体の仮の移動であり、今回の資料を加えても実ビット長にはならない。
実位置の入力は次の4群に整理した。

1. 実ねじの型式・長さ・頭部と座金・駆動穴、着座面、受け側の積層。
2. 対応するビットの品番、装着突出量、係合基準、取付面からの締付TCP。
3. 採用ノーズ・真空管・爪の形状と、供給・接近・締付・復帰の各状態。
4. 工具の向き、ホース型式と経路、取付部、筐体や他の手を含む周辺形状。

今回読んだ公開資料から埋まらない値はJSONでnullのままにした。例示値を採用値に変えて
動作を作る段階には進めていない。工具の採用・締結品質・正式な物理妥当性の判定ではない。
