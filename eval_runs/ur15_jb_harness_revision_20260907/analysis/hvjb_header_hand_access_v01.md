# ヘッダー保持中のねじ軸とH05表面 — v01

2026-09-18。保存済みH05の14保持時点を読み、P16の8軸・P17の6軸から
ハンド表面までの径方向距離を記録した。外側上段の4軸では、キャリアまで
約8.55 mm、黒い機構まで約15.01 mmとなる。これは実工具を配置した結果でも、
その直径を許容できるという判定でもない。

## 測定した対象と座標

- `data/header_review_v03/meshes.json.gz` の全14オブジェクト、51,580三角形を各時点で使用。
  黒い機構10個、キャリア2個、接触パッド2個。パッドも計算から除外していない。
- `motion.npz` の保存frame 575/605/635/665/695/725/755/785 と
  1135/1165/1195/1225/1255/1285。各時点で保存された閉指令との一致を確認した。
  元の表示用締結開始から0.3秒後に最も近い保存配列を選んだもので、実作業時間ではない。
- 元のworld変換から、その時点のヘッダー位置を引いて局所座標へ移す。
  Xは右、Yは筐体側、Zは上。公称取付パターン中央がX=Z=0、CADの取付側基準がY=0。
  軸方向の表示値 `d=-Y` は外側へ正。工具TCPの原点ではない。
- 公称軸は前段 `audit/hvjb_header_fastening_v01.json` から継承。
  元の保存動作が参照したねじ軸との局所XZ対応も照合した。
- H05の全形状はd約−5.0〜97.5 mmにある。−6〜98 mmの52区間へ分けた。
  各区間は2 mm幅の全表面を境界で切り、径方向へ投影した最短距離であり、
  中央一点の断面やAABBまでの距離ではない。表面がない区間はnull。

座標を剛体変換して既存 `probe_hand_tool_access_v01.py` の `_slab_nearest` を使用した。
新しい衝突計算器やFK/IKは作らず、メッシュの縮小・形状の再生成・連続動作の再計算はない。
元nativeはSHAを照合したが、この段でBlenderへ読み込んでいない。観測対象は保存配列である。

## 今回含めないもの

ロボット腕、カメラ、筐体、ヘッダー自体、隣ヘッダー、別の保持手、配線は距離の対象外。
対象14個のすべての面を使用したが、ライン全体の距離ではない。
表面までの半径を2倍して実工具の使用可能径とはしない。
包含、連続動作、たわみ、保持荷重、ねじ反力、締結品質を判定していない。

前段で実ねじ・受け側ねじ深さは未選定。ビット係合、突出長、供給ノーズの形状・開閉域、
ストローク、工具取付変換/TCPも未確定であり、STÖGER例示CADを仮のTCPで載せてはいない。
実工具全体と相手部品の確認は、その構成と座標が対応した後の別観測になる。

H05の60 mm外側配置とT050の40 mm/15°は別設定のまま保持した。
S5_AB、20仕事、92特徴の対応、D60の保持分担、既存nativeを変更していない。
92特徴は全BOM数ではない。物理妥当性の正式判定はVaultProtocol V12の独立経路による。

## 実行時の停止と修正

初回は第3軸の最近点照合で止まり、完成JSONを書いていない。
`audit/hvjb_header_hand_access_v01_stdout.txt` に全文を保持した。
元の距離処理とは別の検査に使ったtrimesh 4.12.2 `closest_point` が、m座標の三角形で
最近点から約8.22 nmずれた辺上の点を返した。関数内部の絶対数値処理と当該座標を保存した。

三角形の原点を引き、最大辺4.5679285 mmで正規化した後に同じ関数で照合すると誤差0。
独立した最小二乗でも、元の最近点は三角形の内部にあり残差0だった。
修正は照合側の座標正規化だけで、距離算出関数、対象面、区間幅、1e-10 mの数値比較値は変更していない。
この値は数値計算検査用で、製造・受入公差ではない。

同じ再現入力で旧検査の失敗と修正後の通過を確認し、面外へ1 µm移した点は拒否された。
再実行の全最近点について照合残差最大8.6126881e-17 m。
既存の解析的形状5件も通過した。`*_witness_diagnostic.json`、`*_validator_check.json` に記録する。
再実行の標準出力は `audit/hvjb_header_hand_access_v01_run2_stdout.txt`。
wrapperのexit 0だけでは完了とせず、例外不在、完了マーカー、JSONの保存読戻しで確認した。

prior-art「ヘッダー/工具/フィンガ」は30件・blocker3・lesson2で停止した。
blockerは旧v05支持部での手首/M4干渉とその複製記録。
現行TEヘッダーH05を読む別対象であり、旧軌道を再実行しない差分を
2026-09-18 10:53:47 JSTのVault logへ記録してから実行した。
