# 締付工具一式の公開CAD比較 v01

2026-09-17。STÖGERの公開例示アセンブリ3形式を取得し、既存PGE比較手先と
同じ縮尺で表示した。先端、給材口、駆動部を含む保存形状を観測できるようになった。
Ampere用の採用機種や取付配置は決めていない。

## 取得した形状と寸法

[メーカーのCAD配布ページ](https://www.stoeger.com/de/downloads.html)から
2D PDFとSTEP ZIPを各3件取得した。URL、サイズ、SHA256、ZIP内のファイル名、
STEPヘッダー、変換後の各境界は `data/hvjb_fastening_cad_v01.json` に収録した。
SESのZIPには英独の補足説明PDFも含まれる。

| 形式 | 用途の区別 | 図面の本体側の寸法例 [mm] | 保存CADの長手方向全幅 [mm] | 表面ノード / 三角形 |
|---|---|---:|---:|---:|
| SES1601 | ねじ締め | 434 | 915.894 | 18 / 812,736 |
| SEM2001 | ナット締め | 629 | 978.700 | 34 / 1,544,017 |
| SEV2001 | 真空保持付きねじ締め | 636 | 1,116.494 | 21 / 885,750 |

図面はいずれも例示寸法で、案件により変わり、モーター側の長さも可変と明記する。
表の2種類の長さは測る範囲が異なる。CAD全幅には保存されている駆動部や端部配線等が
含まれるため、434 / 629 / 636 mmとの直接の一致を要求していない。
元CADの長手方向はSESがY、SEMがX、SEVがZであり、元のX寸法を一律に全長とはしない。

STEPは2016-07-28作成、Autodesk Inventor 2014由来のAP214である。
2026-09-17は取得・観測日で、現行製造仕様の改訂日ではない。
SEM/SEVのZIP内ファイル名にはParasolidという語があるが、内容はISO 10303-21 STEP。

## SES補足説明で読めた内容

`additional_info_SES.pdf` の英語ページで、爪の開放方向は360度、供給ホースの
接続方向は±120度調整可能とされる。接続・センサーは両側に配置可能。
取付面全体で支持し、少なくとも3本のねじとキープレートで固定する案内がある。
工具交換のための移動も図示されている。

これらは方向の調整範囲であり、実際の爪の開き幅・開き角ではない。
今回取得した保存姿勢から開閉途中の形状や給材ホース全経路を作っていない。
図面にあるノーズの径やねじ頭径を、全体の最大外径に置き換えていない。

## 読取りと表示

- 既存 `prepare_hvjb_photo_cad_v01.py` のcascadio 0.1.1による読取りを再利用した。
  既存スクリプトはTEヘッダー4種のファイル名・出力に限定されるため、STÖGERの
  ZIP構成と材質形式を扱う別の読取りスクリプトを用意した。
- STEPの単位はmm。既存条件の線形偏差0.02 mm、角度偏差0.2 radでSI単位のGLBを
  作り、保存ノード行列を適用して境界を集計した。変換後の縮尺変更・間引き・修復なし。
  非表面ノードの除外は3形式とも0件。面積0の三角形は順に70 / 1,630 / 124件あり、
  削除せず記録した。CADからのテセレーションであり、解析曲面そのものの完全一致は主張しない。
- `manufacturer_object_records.json.gz` はノードごとの行列・境界・面数・色を保存する。
  頂点と面の全データはGLBに保持し、JSONへ重複格納しない。これは形状の省略ではない。
- 既存オフライン描画のカメラ計算とpyrenderの処理を再利用した。
  過去のライン構成・動作・参照映像のタクトは流用していない。
- 工具と手先にそれぞれ剛体変換だけを適用し、外形の左端を揃えて上下に並べた。
  工具軸や締結面を一致させた配置ではなく、工具と手先のすきまを測る配置でもない。
  見やすさのための12度の表示回転は、機構姿勢の変更ではない。
- 手先は保存済みPGE_SAMPLEのcontour状態。手先17実体と旧寸法の参考試料4実体を
  全て表示し、線14 mm・追加被覆15.2 mmの試料を実物Ampere寸法と混同しない。
- 全体図は表示X範囲−35〜1,205 mm、先端図は−35〜525 mm。
  各図で工具と手先は同じ縮尺。全体図は両者の境界を全て収める条件を確認した。
  先端図は後部が画面外になることを表示する。
- PNG6枚から可逆WebPを生成して会話表示に収録した。メーカー例示CADの材質色を使い、
  手先の色は比較用。色から材質や機械特性を判定しない。

## 実行中の修正と影響

1. 配布ページの相対リンクが `/de/de/` と解釈され404になったため、公開ページの
   正しい `/de/downloads.html?file=…` を使用した。認証回避や別のCADへの差替えではない。
2. 初回の材質記録が `TextureVisuals.main_color` を参照し例外になった。
   テクスチャ形式では `visual.material.main_color` を読むよう修正した。
   変換済みSES GLB（SHA `9c408900…`）を保持・再利用し、幾何変換を繰り返していない。
   他の2形式は修正後に初めて変換した。
3. 初回描画はPGEの面色とpyrenderのsmooth指定の組合せで例外になった。
   手先の同じ一様色を頂点色として渡すよう修正した。頂点・三角形・行列を変えず、
   新しい出力フォルダで6枚を描画した。
4. 実行前の構文の閉じ括弧と行長・整形も修正した。測定条件への変更なし。

失敗した2回の実行ログはそれぞれ `audit/hvjb_fastening_cad_v01_stdout.txt` と
`audit/hvjb_fastening_cad_v01_render_stdout.txt` に残した。成功ログは
`material_read_stdout.txt` / `vertex_colors_stdout.txt` の同接頭辞ファイル。
Pythonラッパーの終了コードだけに依存せず、例外と完了マーカーを確認した。

工具の締結基準面、開閉途中の外形、供給ホース全経路は未確定。

正式な把持力・締結品質・物理成立の判定は行っていない。今回の読戻し・境界・表示は
補助観測であり、VaultProtocol V12の独立判定経路を置き換えない。
動画は生成しておらず、納品動画1種類の方針もそのまま。

## 再現と記録

`data/hvjb_fastening_cad_v01.json` に取得資料7件、変換条件、全ノード/面数、
全体境界、保護入力SHA、表示行列、画像SHAと表示先をまとめた。
大きな配布CADとPNGは `references/hvjb_fastening_cad_20260917/` および
`previews/hvjb_fastening_cad_v01_material_read/` / `previews/hvjb_fastening_cad_v01_vertex_colors/`
にローカル保持し、Gitには取得URL・SHA・再現スクリプトと監査記録を収録する。

描画は `render_hvjb_fastening_cad_v01.py --conversion <conversion.json> --output_directory <new-dir>`、
会話表示は `build_hvjb_fastening_cad_reference_v01.py --conversion <conversion.json>
--frames <render-dir> --output_html <new-fragment.html>` を既存レンダーvenvの
`isaaclab.sh -p` で実行する。描画には `PYOPENGL_PLATFORM=egl` を付ける。
既存出力を上書きせず、再実行前にはVaultのprior-artガードと具体差分の確認を行う。

`check_hvjb_fastening_cad_v01.mjs` は既存の専用Chrome/CDP確認処理を使う。
736/320 px・明暗・3形式・2視野の24条件で、選択、画像のSHAと縦横比、
表示寸法と記録値、はみ出し、操作欄の重複、JavaScript例外を照合する。
その結果と撮影画像SHAは `audit/hvjb_fastening_cad_browser_v01.json` に保存する。
元PNG6枚と代表的な明暗・大小表示は別に目視確認する。
