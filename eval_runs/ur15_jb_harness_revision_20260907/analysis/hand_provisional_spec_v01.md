# ライン用フィンガの仮仕様 v0.1

2026-09-14。ユーザーの「細部の調整は後でよい、安定してつかむ仕様を早く決めたい」に基づく作業用の選択。

**対向2本指＋対象別の交換指先を基本構成に決め、下表で先へ進める。**
滑りや回転を抑える接触形状を優先する。加工寸法・材質の最適化は後段へ回す。
これは実行側が整理した仮仕様であり、実物で安定保持を確認済みという記録ではない。

## 今回固定する構成

| 種類 | 指／開閉駆動 | 先端と位置決めの構成 |
|---|---|---|
| H01 円形本体用 | 2本／1駆動 | 下受けなしの側面輪郭。側面の平面または取付耳の外縁に当てる回り止め。 |
| H02 角形本体・支持部用 | 2本／1駆動 | 浅い角形ポケット。片側の基準面と長手端当て、対向側の交換パッド。 |
| H03 剛体バスバー用 | 2本／1駆動 | 非接続部の長辺を受ける浅い輪郭と端当て。 |
| H04 ケーブル・丸端子付き配線用 | 2本／1駆動 | T050。端子側の黒被覆と根元被覆を、同じ対向2本指の二つの丸底接触区間で保持。 |
| H05 差込端末・外部コネクター用 | 2本／1駆動 | 剛体ハウジングの専用外形ポケットと、許容された後端・肩の受け面。 |
| H06 筐体・完成品搬送用 | 2本／1駆動 | 幅広対向爪。各爪の離れた二か所に交換パッドと側面輪郭の受けを配置。 |
| H07 カバー搬送・設置用 | 2本／1駆動 | 対向する薄い側縁用ポケットと端当て。長辺に離れた接触域を配置。 |
| H08 ヒューズ本体用 | 2本／1駆動 | 本体形式に対応する交換式の浅い輪郭。円筒は胴の丸底受け、角形は外形ポケット。 |

2本の指の中で、片側を位置決め、反対側を押さえとして使い分ける。
一枚の指に接触箇所を二つ設けても指は2本で、前後は連動して開閉する。
3本指・4本指の追加は今回は選ばない。独立した接触・部分開放の役割が必要になった箇所だけで再検討する。

小物用の基本機構は既存2F-85を再利用する。筐体・カバー用は幅に合う対向爪の搬送ハンドとし、
2F-85で全幅を挟めるとは仮定しない。また、小径線への最小把持力の適合は機種選定時に対応させる。
既存2Fは連動リンクなので、開く途中の爪の上下移動も残る。部品下面に爪を挟む下受けは戻さない。

キャリアで輪郭を決め、接触面は交換式の弾性パッドとする。
ゴムの種類・硬さ・厚さ・力の値は対象ごとに調整する。共通の値を全品へ一括指定しない。
締付工具は腕またはSTへ常設し、フィンガで工具を握らせない。

H01〜H08は手先形状の種類で、ハンド8台やST8台という意味ではない。
同じ手先を共用できる寸法範囲と交換方法は後で対象ごとに合わせる。

## ケーブル用に固定する内容

- 2本指。端子側の黒被覆と、取付部寄りの根元被覆を同時に保持。
- 時計回り15°、傾斜前の後退量40 mm。現在のT050を使用。
- 金属端子・締結穴・接続面は握らない。上押さえは付けない。
- 置いてから離すのではなく、その位置で接続・締結が済むまで保持。
- 両端を扱う作業は両手同時に取得し、保持用の両腕は接続後に同時上昇する方針を継承。
- 二つの丸底接触区間は、軸方向滑り・軸回り回転の形状拘束ではない。被覆と端子の相対ずれも観測対象とする。

**15°と40 mmは現在のサンプルの基準値。**
14 mm線や黒被覆の比較外形を、すべての実配線へ同じ寸法で転用しない。
現物がつかめる黒被覆を持たない場合は、金属クランプへ自動で戻さず、その対象の接触部だけ修正する。
締結反力を被覆で十分受けられることや、両端把持でS字が成立することは、この仮仕様からは確定しない。

## ラインのどこに対応するか

番号は既存ラインとの照合用で、新版のST増設や旧部品の採用を決めたものではない。
3STの担当接続群は既存のA/B/C案を使用し、別ワークを並行処理する方針を維持する。

| 工程の参照番号 | 手先の割付 | 扱い |
|---|---|---|
| OP010 筐体供給 | H06 | 搬送手の方式を仮決め。型式・腕数は別項目 |
| OP020 外部コネクター準備・嵌合 | H05 / H04 | ハウジングをつかみ、必要な線材支持を分ける。空トレーは最新v11の設備返却 |
| OP030-A 本体・支持部の機械固定 | H01 / H02 | 保持手＋フィンガを外した常設工具腕を継承 |
| OP030-B 主回路側の接続 | H03 / H04 / H05 / H08 | 担当部品を同じ位置で保持・接続。両端保持＋ST側2工具の比較方向を継承 |
| OP030-C 補機・制御側の接続 | H03 / H04 / H05 / H08 | 一端操作だけの仕事と両端保持を区別。C全体の腕数を確定した表ではない |
| OP040 旧分岐配索の位置 | H04 / H05 | 追加のD04/6本配線/STは採用しない。新接続群との工程対応で必要な把持だけを割付 |
| OP050 旧クリップ取付 | 追加なし | 旧部品の実物採用なし。手先を新設しない。実部品が決まればH02/H08の許容面に対応 |
| OP060 旧ケーブル押さえ | 追加なし | 撤去済みの上押さえ・青い保持機構を復活させない |
| OP070 カバー設置 | H07 | 実物のカバー仕様に合わせる用途。番号は旧ライン対応 |
| OP080 旧ラッチ取付 | 追加なし | 旧ラッチの実物採用なし。蓋固定がねじなら常設工具を割付 |
| OP090 電気検査 | 追加なし | 検査ヘッド／治具を扱う工程として、把持用フィンガを追加しない |
| OP100 外観検査 | 追加なし | カメラ／検査ヘッドを使い、把持用フィンガを追加しない |
| OUTFEED 完成品払出し | H06 | 筐体の把持面を再利用し、ケーブルを持って製品を吊らない |

## 後で調整する項目と、確認の進め方

構成の決定と、実物での保持確認を分ける。ここからは本表を静的配置の入力として使い、
全用途で細かな寸法最適化が終わるまで構成選びをやり直す進め方にはしない。

| 後段で扱うもの | 調整・観測する内容 |
|---|---|
| 対象寸法への適合 | 型式・線径・許容接触面に合わせる溝径、接触長、ポケット幅、必要開度 |
| 接触と荷重 | 材種、硬さ、厚さ、許容圧、摩擦、把持力。滑り・回転・傷・被覆ずれ |
| 工具と開放 | ソケットだけでなく供給ノーズ一式、相手部品、供給台、カメラとの関係 |
| 腕へ渡す情報 | 取付姿勢、TCP、質量・重心・慣性、開放域、必要な保持腕・工具の役割 |

把持幅と物体検出で空把持・閉じ切りを区別する。ただし、内蔵の物体検出だけで滑りや回転が
検出できるとはしない。取得、停止、姿勢変更、接続中の保持、開放の各状態で対象を観測する。
ケーブルは黒被覆と端子の相対向きを分けて見る。試験回数、力、許容ずれの合否値は今回発明しない。

本段では新たな連続アーム軌道・動画は作っていない。実行側の形状・保存観測と、
VaultProtocol V12による正式な物理妥当性判定を混同しない。

## 根拠

既存の対象表、15°版、専用指先の比較を再利用し、選択を本表へ集約した。
[Robotiqの公式指先仕様](https://assets.robotiq.com/website-assets/support_documents/document/online/2F-85_2F-140_TM_InstructionManual_HTML5_20190503.zip/2F-85_2F-140_TM_InstructionManual_HTML5/Content/6.%20Specifications.htm)
では交換指先を設計できるが、専用形状での力・モーメントを確認する必要がある。標準パッドの定格は転用しない。
既存モデルの取付部は[2018版資料](https://assets.robotiq.com/website-assets/support_archives/document_en/2F-85_2F-140_Instruction_Manual_PDF_20181130.pdf)
との対応を維持し、2019 TM版の取付穴へ置換しない。

部品の範囲は[Ampere公式の公開主要構成](https://help.ampereev.com/hc/en-us/articles/31292470232087-High-Voltage-Junction-Box-HVJB-5-400)
と既存の対象分類に対応する。把持方法は本作業の設計で、メーカーが指定した方法ではない。
機械可読の選択は同梱の `hand_provisional_spec_v01.json` に保存する。
