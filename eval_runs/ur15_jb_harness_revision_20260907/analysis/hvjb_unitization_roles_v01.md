# HVJB ユニット化の支持・工具・受渡し比較

2026-09-16。採用済み5段階を具体化するための比較案。

締結中は **下板を据置治具で支持し、1腕がヒューズ板を保持し、別の据置工具が締める**
構成を比較する。板保持を締結途中で解放しない。締結後に工具を退避し、治具上で搬送用の
把持へ切り替える。搬送時はユニットの支持と自由端案内を分けて扱う。
役割は手先・腕の台数と同じではなく、正式な腕数・機種・実寸配置はまだ選定していない。

Q4以降は採用したねじ固定が完了し、板間で荷重を受けられるという**工程上の想定**。
実物での荷重確認ではない。Q5の持ち替え中も下板は治具が支える。
この想定が成立しない構造では、板保持を途中で解く本案は使えない。
Q6の治具解放とQ8のハンド開放は、相手側への支持の引継ぎ後に置く。
信号・検出方法・力・トルク・合否値は定めていない。

## 先に詰めるインターフェース

1. **下板の支持面**：現モデルに独立した可搬下板がない。P01の筐体底面を流用しない。
2. **ヒューズ板のつかみ代**：H07の薄い板縁用2本指を比較の起点にする。P07は概略外形で、
   全輪郭・板厚・工具穴・許容接触域が確定したCADではない。
3. **工具の方向**：板間ねじの軸方向が未確認。縦から締める図やXYZで足りる前提を作らない。
4. **搬送指の抜け方**：下板側を持つH06系の対向爪を比較する。筐体内で横に開けるかが未確認。
   部品下面へ爪を挟む形、未確認の吊り耳・穴、ケーブルや接触器を吊り手にする形を追加しない。
5. **自由端**：H04/H05を対象別に対応する。1つの手で全端末を同時に扱えるとはしない。
6. **筐体側の受け**：内寸・支持面・固定点を対応してから、ハンド開放の幾何を作る。

据置治具に下板の支持を任せる案なら、締付のためだけにもう1本の多関節腕を増やさずに
比較できる。板保持と一体搬送の腕を共用する案では、手先の互換性・交換と、治具上の
持ち替え時間を別途扱う。3腕は同時に必要な独立仕事が残る場合だけ比較する。
本案から3STの正式配置や実機タクトは算出していない。

## モデルと出典の扱い

保存済みメッシュ書出しを読取り、P01の部品名、P07の概略外形、可搬下板IDの有無を記録する。
工程表v03・観察台帳・既存nativeは保持する。図は無寸法の役割図であり、衝突回避軌道ではない。
2022年の製品写真と2025年の組立品は同一製造版が未確認のため、図へ実寸座標を混ぜない。

[Carr Laneの公式原則](https://www.carrlane.com/engineering-resources/fixture-design-principles/locating-clamping-principles)
を参照し、位置決め、保持、荷重を受ける支持面、工具の通路を分けて検討する。
これは一般原則の適用で、Ampereの治具構造・把持面・必要力の出典ではない。
H01〜H08の既存仮仕様と、原画像を保持する確認ページ生成処理を再利用する。
板支持専用の実物CADが未取得のため、今回の追加実装は工程比較の表示に留める。

下流の筐体固定・端末引出し・ヘッダー・バスバー／残接続・蓋／検査／払出しを残す。

T050の40 mm・15度、上押さえを復活させない指定も維持する。
次の実寸モデル作業は、独立下板・接合部・把持域・工具包絡・開放域の対応から始める。
