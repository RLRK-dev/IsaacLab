# 先端・根元のパッド追従と保持力条件 v01

2026-09-14。40 mm後退と二か所保持のv03を基準に、次の比較と測定入力を整理した文書です。
材質・力の値を確定した製作仕様や、物理的な受入判定ではありません。

## 1. まず比較する構成

**端子側は位置と向きを決める輪郭を保ち、根元の交換式パッドで寸法差に追従させる案から比較します。**
元の2本指・単一駆動を使い、左右各指に前方と根元の接触部を持たせます。
接触箇所が4つあっても、4本の独立した指や4軸の力制御にはなりません。

| 部位 | 役割 | 次に確かめること |
|---|---|---|
| 端子側 | 端子の位置・向きを決め、締結中のずれを抑える | 圧着後輪郭、許容接触面、接触層を含む剛性と公差 |
| 根元側 | 被覆を丸底パッドで支え、前後の接触開始のずれに追従する | 被覆径、実形状の圧縮特性、摩擦、保持時間中の力低下 |
| 青い延長部・取付け | 二つの接触部から来る荷重を元末節へ伝える | 曲げ・ねじり・変位、取付穴と工具のアクセス |

先端は後方4〜12 mm、根元は61〜71 mmの接触区間を維持します。40 mmは指定された初期後退値です。
参考線φ14、根元中央パッド厚さ約2 mm、接触長さ10 mmはv03の比較形状で、実物の採用寸法ではありません。

根元パッドの許容圧縮だけでは寸法差に追従できない場合に、開閉方向へ案内される受動パッドを第二案として比較します。
現在の根元支持部の幅は3 mmです。案内・復元要素・移動止めがその中に収まると仮定せず、寸法検討から行います。
今回はその機構や別の駆動軸を3Dモデルへ追加していません。

## 2. 硬さだけで保持力を決めない

Robotiqの公開材料説明には、シリコーン指先の参考としてShore A60が示されています。
一方、ユーザー提供のG3/G4仕様v0.2のA30〜50・厚さ3 mmは、別の新規グリッパー案の仮設定です。
どちらも、この延長指先の採用値にはしていません。[Robotiq 材料説明](https://blog.robotiq.com/knowledge/what-material-are-robotiq-grippers-and-fingertips-made-of)

Robotiqは、シリコーンを厚くして位置ずれへ追従させる設計例を説明しています。
これは比較の根拠になりますが、今回の被覆に許される押付力や圧縮量を与えるものではありません。
[Robotiq カスタム指先の設計例](https://blog.robotiq.com/how-to-design-custom-fingertips-for-your-application)

硬さの番号をばね定数へ直接変換せず、実際の丸底形状・厚さ・支持方法で圧縮量と反力を測ります。
保持中の力低下、戻り、表面の摩擦、繰返しによる変化も別の項目です。
応力–ひずみデータを使って選ぶ方法の参考として、RogersのCFDツールを参照しました。材料の採用や被覆との摩擦値を決定したものではありません。
[Rogers CFDの説明](https://www.rogerscorp.com/elastomeric-material-solutions/bisco-silicones)

## 3. 同じ駆動で二か所を挟むときの課題

根元だけ先に当たると、その後の閉動作を根元のパッドなどが吸収しなければ先端へ荷重が移りません。
逆に根元が遅く当たると、先端だけが押される区間ができます。したがって、柔らかさと接触開始位置を合わせて決めます。
これは一般的な接触モデルからの設計上の推論で、v03の保持力を測定した結果ではありません。

v03は根元の面を参考線へ合わせていますが、前方輪郭には0.1 mmの表示用隙間があります。
この値は実物の公差・許容圧縮・設定ストロークではありません。形状確認を、そのまま両方に力が掛かった状態とみなしません。

確認ページの図は、片側の指を「二つの独立した線形ばね」で置き換えた一次説明です。
端子側が接触を始める位置を閉じ量c=0、根元が早く当たる量をeとします。

```text
δT = max(c, 0)
δR = max(c + e, 0)
FTx = kT δT
FRx = kR δR
```

表示する力は `Fx / (kT × 1 mm)` の相対値です。Nへの換算はしていません。
c、e、剛性比のスライダー範囲と初期値は説明用で、実物の設定や許容範囲ではありません。
図はX方向の一次反力だけを扱い、実際の丸底面の圧力分布、ケーブル変形、リンク機構、摩擦、モーメント、動作は含みません。
この反力を実接触面の法線力や摩擦保持力として流用しません。

## 4. 4接触部の力と、実際の保持条件

接触部をTL/TR（端子左/右）、RL/RR（根元左/右）として区別します。
把持力の合計だけを見ず、各接触部の押付力・接線方向の力・圧力分布と、ワークに対する外力の経路を確認します。

| 確認する量 | 根拠になる入力 |
|---|---|
| 摩擦で受けられる接線方向荷重 | 実材の摩擦と接触圧分布。参考の油付き鋼材の摩擦値をケーブルへ転用しない |
| 被覆や端子へ掛けられる押付け | 部品メーカーとRsが定める押付力・圧力・変形の条件 |
| すべり・回転を抑えるための反力 | 搬送、曲げ、位置合わせ、締結それぞれの外力・モーメント |
| 指と取付けへ伝わる荷重 | 接触位置、各力、元末節からの距離、実材と取付け |
| 指令値と接触力の関係 | 当該ハンドの開度・接触位置・摩擦・力の対応の測定 |

摩擦の局所関係 `|τ| ≤ μp` と、ワーク全体の力・モーメントの釣合いを同時に扱う必要があります。
二つの接触面の摩擦容量を足すだけで、任意方向の荷重や回転に耐えるとは判定できません。
反力経路と必要な余裕が未確定なので、今回は把持力を何Nにするか、左右や前後を何対何にするかは定めていません。

ねじの設定トルクが全量ハンドへ来るとも仮定しません。工具、ねじ、端子、ケース、パレットの支持関係に応じて、ハンドへ実際に伝わる反力を区別します。
モーター電流や手首の合力だけから、前方と根元の両方に保持力があると断定しません。
測定用治具などで各接触部を区別する方法を検討します。常設センサーの型式・数は今回追加していません。

## 5. 2F機構で残る照合

Robotiqの2Fは単一駆動の適応機構で、物体形状や接触位置によって平行把持と包み込み把持が変わります。
カスタム先端にもequilibrium lineの条件が残ります。このため、保存された4姿勢だけから負荷時も同じ把持モードになるとはいえません。
[Robotiq 機構説明](https://assets.robotiq.com/website-assets/support_documents/document/online/2F-85_2F-140_TM_InstructionManual_HTML5_20190503.zip/2F-85_2F-140_TM_InstructionManual_HTML5/Content/1.%20General_Presentation.htm)

元モデルに対応する2018説明書p131でも、この制約を確認しました。取付穴は前回照合した2018世代を維持します。
一般動作を説明する2019 HTMLを、新しい世代の取付図や延長品の力の認定に使いません。
[2018説明書](https://assets.robotiq.com/website-assets/support_archives/document_en/2F-85_2F-140_Instruction_Manual_PDF_20181130.pdf#page=131)

## 6. 数値を埋める順序

1. 採用電線・圧着後端子の把持面と寸法範囲を確認する。
2. その表面と実形状パッドの圧縮・摩擦・圧力分布・保持時間中の変化を測る。
3. 取付けた状態で接触開始位置、開度、指令値、4接触部の力と把持モードを対応させる。
4. 工程ごとの荷重・反力経路・許容すべり等と突き合わせ、力設定の候補を絞る。

比較用データの `required_inputs` は16項目を列挙し、実測値と力指令はすべて未入力です。
合否しきい値は発明していません。正式な物理妥当性判定はVaultProtocol V12の独立レビュー経路で行います。
形状のユーザー確認と、実部品を用いる把持条件の確認を分けて記録します。
