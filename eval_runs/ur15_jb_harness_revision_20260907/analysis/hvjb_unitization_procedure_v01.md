# HVJB 現時点で採用するユニット化手順

2026-09-16。ユーザーの「ok 現時点ではその手順でよい」により、以下の5段階を
工程検討の基準として採用した。Ampere実物の固定方法を確認したという意味ではない。

| 順序 | 作業 | 工程表での位置 |
| --- | --- | --- |
| 1 | 下板側ユニットを位置決めして支持する | O30 / UZ01 |
| 2 | ヒューズ板側を所定の位置・向きに合わせる | O30 / UZ02 |
| 3 | 姿勢を保持しながら、ヒューズ板側を下板側へねじ固定する | O30 / UZ03 |
| 4 | 未接続のケーブル・端子・コネクタを搭載経路からよける | O30 / UZ04 |
| 5 | まとめたユニットを、自由端を案内しながら筐体へ搭載する | O40 / UZ05 |

**箱外でねじ固定してから一緒に搭載する流れを、現時点の手順とする。**
実物の固定方法が映像で見えないことを理由に、この工程選択まで未選定へ戻さない。
仕様の具体化では、下記の未確定部分を別に扱う。

- 直接固定か、ブラケット・支柱を介するか。支持部の形状・寸法。
- ねじ位置・本数・規格・締付トルク、具体的な保持面と工具接近。
- 正式なST配置・腕数・機種・タクト。

筐体への固定と残りの配線接続は、搭載後の作業として残す。
内側端末の開口引出し、外側ヘッダー、バスバー・残接続、蓋・検査・払出しを省略しない。
前段のケーブル退避と、搭載後に端末を側面開口へ通す作業は別の手順である。

OP010のXYZ＋20個収納、OP020の筐体側ヘッダー設置・ねじ固定を継承する。
P01の筐体底面を可搬下板に流用せず、上押さえや撤去済みの外側保持具を復活させない。
今回の採用は手順の指定で、把持・締結の物理妥当性や受入条件の決定ではない。
