## 1. 5.9 mm は現構成の値ではない

§5.3 の表で**唯一の実測値**が 5.9 mm で、「現行 / 自己干渉」の欄に入っている。
出典を引くと組はこうである:

| | オブジェクト | タグ |
|---|---|---|
| moving | `OP030C__source_1054_m0309_p00` | **`robot_OP030_left`** |
| obstacle | `source_1136_m0304_p00` | **`robot_OP040_left`** |

**二重に違う。**

1. **相手は OP040 のロボットである。** 同一支柱に載る 2 本の腕どうしではない
2. **moving 側は S3R の鏡映コピー**、すなわち**案② が建てるもの**である。今立っているものではない

`HANDOFF_v07.md` §11-18 の原文も
「**C のコピーの腕**から **OP040 の腕**へ測ると 0.0186 m、逆向きに 0.0059 m」と書いており、
**元の記述は正しい。§5 に運ぶときに取り違えられた。**

⇒ **§5.3 の「現行」行の自己干渉欄は、空にするのが正しい。**

## 2. 自己干渉は測られていない。しかも現行プローブでは測れない

committed の JSON 49 本を掃いた。タグの付いた組 38 件のうち、
**`robot_OP030_left` × `robot_OP030_right` は 0 件。**

原理的な理由がある。`probe_op030_v07c_mirror_clearance.py` の

```python
def obstacles(exclude: set[str]) -> ...:
    """Return every object that is not moving, with its world box [m]."""
```

は **moving でない全オブジェクト**を返す。セルの moving 集合には**両方の腕が入っている**ので、
**左腕 × 右腕は候補にすらならない。** さらに三角形段階は moving 側だけを鏡映する
（`mirrored_geometry(moving, station_y)`）。

**このプローブは「コピーが何の中に建つか」を問う道具であって、
「セルが自分に何をするか」を問う道具ではない。**

⇒ 測るには**別の測定が要る**。必要なのは
**1 セル内の moving × moving を、1 フレームではなく保存バンク全区間で**取ること。
（`HANDOFF_v07.md` が作業6 に先送りしている件と同じ対象。）

## 3. 構成の実測（本書が初出）

### 3.1 支柱と肩

セルごとに床置きの組立体 `source_0578`（`assembly_cell_03` タグ、9 部材）が 1 本だけあり、
**Z 0.370 → 1.626 m**。両腕の肩はその上に載る。

肩は各腕の鎖の先頭リンク（`source_1046` / `source_1086`）で取った。姿勢で動かない。

| | セル A | セル C |
|---|---|---|
| 左肩 | X −0.9000 / Y −1.9327 / Z 1.5427 | X −0.8204 / Y +2.6813 / Z 1.5427 |
| 右肩 | X −0.9000 / Y −1.4673 / Z 1.5427 | X −0.9796 / Y +3.1187 / Z 1.5427 |
| **肩ピッチ** | **465.5 mm** | **465.5 mm** |
| 肩の高さ | 1.5427 m | 1.5427 m |
| 中点 | X −0.9000 / Y −1.7000 | X −0.9000 / Y +2.9000 |
| 中点＝ステーション中心 | **はい** | **はい** |
| 肩線の向き | Y 軸に平行（0°）| **20.0° 振れている** |

**A と C は同一の双腕ユニットで、C は鉛直軸まわりに 20° 回してあるだけである。**

両肩とも支柱のフットプリント内にあり、高さも一致する。**§5.2 の「同一支柱・Y 字」は正しい。**

### 3.2 効いてくる寸法

**両方の道具はステーション中心で会わなければならない。** 中心は各肩から
**232.7 mm**（＝ピッチの半分）である。**肩が 465.5 mm しか離れていないところへ、
2 本が内向きに 232.7 mm ずつ寄る。**

⚠ **保存姿勢では 2 本の箱は 295.8 mm 離れている**（3 セルとも同値）。これは
**待機姿勢で互いに外を向いている**ためで、**作業姿勢ではない。**
在庫は 1 フレームであって掃引ではない。**この 295.8 mm を余裕と読んではならない。**

### 3.4 2 本は共有ヨー軸に載る（§5 のどこにも書かれていない）

`scripts/op030_motion.py` の `phase()`:

```python
if turn is not None:
    transform = turn_frame(turn)
    ...
    self.hands = [transform @ hand for hand in self.hands]   # 両手に同じ変換
    self.yaw += turn                                          # ヨーは単一のスカラ
```

`turn_frame` はセル中心 `(CX, CY)` まわりの回転である。

⇒ **旋回は「腕の動作」ではなく「ヨークの動作」**であり、**2 本が一緒に回る。**

**したがって、工具（左腕の M4 スピンドル）も供給側へ運ばれ、戻ってくる。**
支持部 1 個につき 2 回、1 サイクルで 4 回。

**工具そのものは恒久取付である** — `op030_split_support_motion.py` の要約行は
「**a permanent left-arm M4 spindle**」で、`driver_home()` は**待機位置**であって
ストッカのセルではない。**ストッカ「から」取るのではなく、ストッカ側「へ」運ばれる。**

**旋回するのは A だけである。** B（`op030_split_wire_motion.py`）と
C（`op030_split_fastening_motion.py`）は `turn` を一度も呼ばない。
**共有ヨーは A の部品供給の仕組みである。**

#### §2.6 の内訳の読み替え

§2.6 は「押さえ腕が持っているだけ 43.2 秒（41%）」を
**M4 取得 31.7 ＋ 旋回 11.5** で構成している。**この 2 つは性質が違う:**

| 内訳 | 秒 | 実体 | フィーダ内蔵で消えるか |
|---|---|---|---|
| M4 取得（供給器往復 ×2）| 31.7 | **本当の待機。** `op030_fastener_operations_v04.py` は `turn` を呼ばない（0 件）ので、左腕だけが往復し右腕は保持して待つ | **消える** |
| 旋回（×2）| 11.5 | **共有ヨークの動作。** どちらの腕も作業していない。「押さえ腕が締結腕を待つ」ではない | **消えない** |

⇒ **§2.6 の結論「フィーダ内蔵は押さえ時間の短縮」は 31.7 秒については正しい。**
**ただし 43.2 秒という括りは、フィーダでは触れない 11.5 秒を含んでいる。**
§4 のタクト計算は 31.7 しか引いていないので、**数字自体は影響を受けない。**

## 4. 構成の判断に効くこと（ここからは推論）

**事実は §1〜§3 まで。ここから先は本書の読みである。**

§5.3 の表は**3 セルに 1 つの構成を当てる**前提で書かれている。
道具の割付を見ると、**3 セルの要求は同じではない**:

| セル | 2 本が同時に同じ場所を要るか | 共有ヨーを使うか | 共有基礎の価値 |
|---|---|---|---|
| A | 押さえと締結で**同時に要る** | **使う**（供給側へ 180°）| **高い。分けると供給の仕組みが壊れる** |
| **B** | **ケーブル両端で同時に要る**（§5.1）| 使わない | **相対精度の点でここだけ本質的** |
| C | **要らない**（M6 と M14 の直列）| 使わない | **買うものが無い** |

⇒ **C は分離の代償が最も小さい。** §5.3 の③（対向）や④（別支柱）を試すなら C からである。
⇒ **B は相対精度の点で共有基礎の理由が立つ唯一のセル。**
⇒ **A は共有ヨーそのものが部品供給の仕組みである。**
**③（対向）は別基礎なので共有ヨーを持てない。** 背面ストッカへ 180° 振り向く動作が成立しなくなり、
**A には「相対精度が劣る」以上の代償がある。**

⚠ **初版は「A の論点は押さえに 6 軸腕が要るかだ」と書いた。狭すぎた。**
右腕は供給キットからの搬送も担い（§3.3）、その搬送はヨークの旋回に依存している（§3.4）。
**押さえだけを見て腕を減らす議論はできない。**

**ただし、この分解は「同時性」と「供給の仕組み」だけで判断している。** 干渉も、
相対精度の要求値（問い d）も、**まだ数字が無い。**

## 5. 決まらないこと

- **自己干渉の実測がまだ無い**（§2）。§5.3 の表に自己干渉の欄がある以上、
  **現行行に入れる数字を作らないかぎり表は埋まらない。** 必要な測定は §2 の末尾に書いた
- **問い d（両端保持に要る相対精度）は実物のケーブルの性質**で、モデルからは出ない。
  §5.3 の「相対精度」列は**全行が未計測**である
- **B の配置が commit されていない。** B は §5.1 が「双腕が還元不能な唯一のセル」と
  呼ぶセルなので、**測れないセルが論点の中心にある**
- 本書は保存姿勢 1 フレームしか見ていない。**掃引ではない**
