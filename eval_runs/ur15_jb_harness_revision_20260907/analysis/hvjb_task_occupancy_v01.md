# HVJB 仕事・対象・保持区間 v01

2026-09-16。少数のロボットへの集約案を、仕事ごとの対象と占有へ展開する。

## 今回具体化したこと

工程v03の12作業へ対応する20仕事について、取得開始、保持継続、担当を終える区切り、
次の兼務候補を記載した。これは時間未設定の作業票で、実行するロボットプログラムではない。
同梱の確認ページで仕事を選ぶと、その保持区間、据置工具、追加保持役と対象の照合先を確認できる。

- P16の3口ヘッダーはM4の8穴、P17の2口ヘッダーは6穴。TE図面に基づく既存台帳から継承した。
  それぞれ対象穴群の締結と工具退避まで保持を続ける。同じ保持腕・工具を順次使う候補で、
  14穴を14台や14秒へ換算しない。穴の施工順・締付条件・工具全外形は未確定。
- R-Cは板保持、治具上の持ち替え、一体ユニット搬送を順次兼務する候補。
  持ち替え中もR-Cの担当作業が残り、自由に他セルへ移動できる時間とは数えない。
- X-Cを使う自由端案内は、搭載が終わっても自動で空きにしない。開口通過、内側端末の支持と
  ヘッダー作業への引継ぎまで、どの役が支持を続けるかを追う。
- **内側ハウジングを持っている同じ手では、外側ヘッダーを新たに取得できない。**
  次の手への引継ぎまたは支持方法が必要。その役をX-Cへ割り当てる比較を残す。
  上押さえの復活や、未締結端末の放置を前提にしない。

## 対象との対応

写真台帳の42部品特徴、23締結特徴、27配線区間の計92特徴を一行ずつ照合欄へ残した。
部品群の工程対応、締結特徴の写真上の親、可視配線の入口外装を保存記録から引き継ぐ。
「照合する仕事」は候補であり、実際にその全仕事を施工する指定ではない。

23締結特徴の親IDだけでは、本体の機械固定か電気端子か、積層・共締めを確定しない。
ヘッダーの14穴はこの23特徴とは別の図面記録で、合算して製品全体の締結点数と扱わない。
27区間も27本の線や27回の搬送ではない。電気13群を物理線に置き換えない。

17必須機能、電気13群、LV12極、既存の準備・組立依存関係を確認ページとJSONへ収録した。
LV6/12のReservedは維持する。未配置の抵抗、実物端子、全線の両端が未確定でも仕事を削除しない。
2025年映像の6観察対象は別枠に置き、2022年写真の部品や92特徴へ自動統合しない。
下板P01流用や架空の板間ねじ点は追加していない。

## 台数集約への使い方

1. 各仕事の対象接続・全ての同時保持役を決める。
2. 取得、保持、工具待ち、解除、退避、手先交換までを占有として記録する。
3. 順次兼務候補の所要時間と到達範囲を埋める。
4. 補助役の引継ぎとセル間移動を含め、3ST並行を維持できる共有案を比較する。

今回は1の照合と2の区切りを具体化した。時刻・秒数・タクト・最小台数は未計算。
保持を終える区切りは工程上の想定で、センサ条件・把持力・締付品質・物理受入条件を新設しない。
ユニット化後の持ち替えは、採用した板間固定が荷重を受ける想定に依存し、未検証のまま明記する。

`hvjb_robot_allocation_v01.json`、`hand_provisional_spec_v01.json`、支持受渡し9場面を再利用。
