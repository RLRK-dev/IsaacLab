# HVJB 板間の合流・固定箇所の追加照合 v01

2026-09-16。前回の開口修正に続き、下板とヒューズ板の接合、および筐体への固定を調べた。

**合流前後が見えるのは、公式映像の87.0秒と87.2秒の編集境界だった。接合する動作は追えない。**
加えて、2022年の公式追加写真に固定部候補の見える箇所を2件記録した。
ねじの裏側・締結相手は未確認で、モデルの接合やアーム動作は作成していない。

## 映像の境界

原本：[Ampere EV公式組立映像](https://www.youtube.com/watch?v=Sm_D-vmNYqc)。
保存原本SHA `b7fcb74eaeec06e517d5726994a38a6b0812e05198d8b771b7ff771e68a0e1eb`。
追加の16場面から境界を絞り、87.0〜88.2秒を0.2秒刻みで7枚抽出した。
抽出前後で原本のSHAは一致。フレームは無加工で、表示用の番号だけをHTMLで重ねる。

| 参照時点 | 見える状態 | 分からないこと |
| --- | --- | --- |
| 87.0秒 | 手前にヒューズ板側、奥に下板側が別置き | 板の接合面・裏側 |
| 87.2秒 | 画角・姿勢が切り替わり、ヒューズ群が奥の下板側に見える | 移動・組合せ・固定の実際の作業内容 |
| 133秒 | 筐体の包装を外す。板側の部品群は台上 | 板間固定の状態 |
| 146秒（既存抽出） | 下板側とヒューズ板側を同時に筐体へ運ぶ | 剛結の有無、固定仕様、自動保持方法 |
| 158秒（既存抽出） | ドライバーを箱内へ入れる | 遮蔽された工具先端の作業点 |

カットの厳密なフレーム番号は未測定。**0.2秒は抽出時点の差で、実物の組付け時間ではない。**
この間に何本のねじを締めたか、仮置きのみか、結合済みかは定めない。
64秒・66秒の抽出画面は完成写真の挿入で、組立途中の状態としては使わない。
全16枚を連続観察した記録ではなく、確認ページに記した場面の補助観察である。

## 工程・モデルへの反映範囲

O30の合流／同時搭載、O42の搭載後工具接近という工程対応を維持する。
新しい記録には、合流作業の見えない編集境界と、まだモデルに対応していない2箇所を残した。
見えない板間ねじや支持金具を作成せず、P01の筐体底面を可搬下板に変更しない。

写真台帳92特徴、17必須機能区分、13接続群、LV12極は元のまま。
2観察箇所を足して94部品とはしない。p03の静止nativeと旧版、工程JSON v02は保存し、
新動画を作らない。正式な物理妥当性の判定を含まない。

今回の公開ページ探索でも、板間接合の寸法図・固定点の資料は取得できなかった。
公式ヘルプのFull Documentation / CADはログイン案内のため未取得。
忠実な接合モデルへ進むために残る入力は、板間の接合断面・締結相手と、下板から筐体への
固定点・支持面。外形写真の追加だけでこれらが確定したとは扱わない。
