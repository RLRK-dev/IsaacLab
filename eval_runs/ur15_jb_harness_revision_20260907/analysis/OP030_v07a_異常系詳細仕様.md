## 1. 方針

現行の 7分49秒は成功系のみで、異常事象は 0 件。**スキルの選択・遷移・回復という WMSO の中身が、映像にも保存データにも一度も現れていない。**

v07a はこれを埋める。造形物と機構は原則として追加せず、**既存フェーズの再構成だけで復帰動作を作る**。追加するのは E3 の排出シュート 1 点のみ（§4.3）。

## 3. 世界モデルの役割

異常を例外処理として書かず、**「次スキルの実行初期状態が満たせるか」の判定として表現する**。

- 各スキルは事前条件（実行初期状態）を持つ。
- 世界モデルが現在の観測から次スキルの事前条件を満たせるか判定する。
- 満たせない場合、満たせる状態へ運ぶ復帰スキルを選び、その実行初期状態を準備してから起動する。
- 復帰後は指定の合流スキルへ戻る。

この構造なら、事象が増えても分岐が増えるのではなく、**スキルと事前条件が増えるだけ**になる。

## 4. 4事象の定義

### 4.1 E1 — 支持部の把持失敗（ST A）

| 項目 | 内容 |
|---|---|
| 注入点 | A の `T{n}／対向マーク面で絶縁支持部を把持`（`Sequence.grasp` の第4サブフェーズ 0.8 秒）直後 |
| 観測量 | 指開度（想定 52.40008 mm）、オンハンドカメラによる支持部の有無 |
| 判定 | 指開度が想定値より小（空振り）または支持部が視野にない |
| 復帰スキル列 | 解放相当 2.7 → 再進入・把持 6.8 → 再判定 |
| 推定復帰時間 | **約 9.5 秒** |
| 合流点 | `T{n}／格子パレットから持上げ` |
| エスカレーション | 2 回失敗で**同一格子の別個体へ切替**。格子は 20 個で 1 製品あたり 2 個しか使わないため、18 個の代替在庫がある |

**この事象は在庫で吸収できる**のが利点。ラインを止めずに個体を替えられる。

### 4.2 E2 — 端子の未着座（ST B / ST C）

| 項目 | 内容 |
|---|---|
| 注入点 | B フェーズ 10 `H03-2／T端子を40mm下ろして着座`（H03-1 は 26）の完了時。C は `低速ねじ進行・着座` 6.0 秒の完了時 |
| 観測量 | T端子 Z の残距離、着座荷重、締結側はトルク曲線 |
| 判定 | 残距離 > δ、または着座荷重 < F_min |
| 復帰スキル列 | **指を開かずに** 40mm 戻す 3.0 → 同軸やり直し 2.2＋1.5 → 再度 40mm 下ろす 3.0 → 再判定 1.0 |
| 推定復帰時間 | **約 10.7 秒** |
| 合流点 | B フェーズ 11 `両端の受けに支持を移す` |
| エスカレーション | 3 回失敗で製品を不適合としてマークし、後工程へ通さない |

**現行との差は「開く前に判定する」一点。** 開いてしまうと復帰に 1 本分（63.1 秒）かかる。判定を 1 フェーズ手前に置くだけで、復帰時間が 6 分の 1 になる。

### 4.3 E3 — M4 の噛み込み（ST A）

| 項目 | 内容 |
|---|---|
| 注入点 | A の `T{n}／右保持のままM4{±}締結` のうち `低速ねじ進行・着座` 6.0 秒の途中 |
| 観測量 | トルク曲線と回転角の関係 |
| 判定 | 規定角度に達する前にトルクが上限を超える |
| 復帰スキル列 | 逆転 6.0 → 軸方向退避 1.8 → 上方退避 2.0 → **不良ボルトの排出 2.0** → 再取得 16.6 → 締結の再実行 20.5 |
| 推定復帰時間 | **約 48.9 秒** |
| 合流点 | 同じ締結座への `fastener_drive_append` |
| エスカレーション | 2 回失敗でその締結座を不適合としてマーク |

**排出シュートを 1 点追加する**（2026-09-11 決定）。不良ボルトの排出先が現行モデルに存在しないため、追加しなければ排出先が未定義のままとなりトレーサビリティが成立しない。排出を省略すれば造形変更は避けられる（復帰 46.9 秒）が、工程内保証の観点から採らない。

v07a で追加する造形はこの 1 点のみ。

| 項目 | 内容 |
|---|---|

## 5. 実装方式

### 5.1 分岐を持つ bank ではなく、事象注入版の bank を作る

現行 `op030_split_b_stagger_v06:build_sequence_final(config)` は 33 フェーズを直列に組む factory。分岐構造を持たない。

最小の実装は、**正常 bank に加えて事象ごとの復帰込み bank を生成する**方式にする。

- `build_sequence_fault(config, fault_id, inject_at_frame)` を追加する。
- 正常フェーズ列を `inject_at_frame` まで再生し、復帰スキル列を挿入し、合流点から正常フェーズ列を続ける。
- 出力は `data/op030_split_b_stagger_v07a_E4.npz` のように事象ごとに分ける。

この方式なら、**既存の replay / native readback / render / encode パイプラインをそのまま使える。** 新しい機構や動力学を定義しない、という v06 scope の原則を維持できる。

### 5.2 再現性は乱数ではなく決定論で担保する

`inject_at_frame` を config に固定値で持ち、同じ config から同じ bank が再生成されることを保証する。乱数とシードは使わない。既存の隔離再ベイク（23 入力）と同じ検証がそのまま使える。

## 6. 平均タクトへの影響

案④（タクト **72.1 秒**・6 セル、`OP030_v07b_再分割詳細仕様.md` §4 の訂正値）に対して。平均タクト = タクト ＋ セル数 × 異常率 × 復帰時間。

| 1セルあたり異常率 p | 人手復帰（300秒・全停止） | WMSO 自動復帰（平均 33.1秒） | 差 |
|---|---|---|---|
| 1% | 90.1 秒（−20.0%） | 74.1 秒（−2.7%） | 17 ポイント |
| 3% | 126.1 秒（−42.8%） | 78.1 秒（−7.6%） | 35 ポイント |
| 5% | 162.1 秒（−55.5%） | 82.0 秒（−12.1%） | 43 ポイント |

**異常率 5% でも自動復帰があれば劣化は 12% に収まり、人手復帰では 56% 劣化する。**

> **2026-09-12 追記 — この式の適用範囲。** 平均タクト = タクト ＋ セル数 × p × 復帰時間 は、
> **各セルで同じ p、かつ 1 回の復帰損失がすべて加算される**という条件付きの試算である。同期
> ラインでも、律速でない工程の復帰が待ち時間に収まる場合や、複数セルが並行して復帰する場合は
> 単純加算と一致しない。局所復帰・共通停止なし・搬送開始時に全 ST の完了を待つという簡略条件
> なら、1 サイクルごとに T = 搬送時間 ＋ max_i(通常処理_i ＋ 遅延_i) で評価できる。
>
> また **33.1 秒は 4 事象の等重み平均（33.05 秒の丸め）であり、実測平均ではない。** 事象ごとの
> 発生頻度が違えば平均も変わる。括弧内の −20.0% 等はタクトの減少率ではなく**名目生産数の
> 低下率**である。

E4（63.1 秒）が平均を押し上げているため、**E4 の復帰時間を削ることが最も効く**。ただし §4.4 のトレードオフがある。

## 7. 検証項目（何をもって成立とみなすか）

既存の確認と同じ基準を適用する。

1. **幾何**: 復帰込み bank の全フレームで、動作対象の意図外交差 0。実メッシュで確認する（現行 B と同じ基準）。
2. **軌道の復元**: 復帰後の製品状態が、正常 bank の同時点の状態と行列一致すること。**これが「復帰が元の軌道に戻った」ことの証明になる**。最も重要な検証項目。
3. **個体の追跡**: E4 で個体が替わっても UID の所有関係が保たれ、落下個体が製品へ渡らないこと。E3 で排出したボルトが製品へ渡らないこと。
4. **線長・材点**: 被覆中心線長と把持材点が保存値と一致すること（現行 B は誤差 6.19×10⁻¹⁴ m）。
5. **速度・加速度**: 復帰動作が映像用上限 1.2 rad/s・2.0 rad/s² 以内であること。
6. **再現性**: 同じ config から同じ bank が再生成されること。隔離再ベイクで確認する。

## 8. 未確定・Rs 裁定事項

1. **しきい値**: δ（着座残距離）、F_min（着座荷重）、トルク上限、指開度の許容差。**すべて未定。実測または仕様からの決定が要る。**
2. **エスカレーション回数**: E1 は 2 回、E2 は 3 回、E3 は 2 回としたが根拠はない。
3. **異常率 p**: 現行モデルに異常事象が 0 件のため、§6 の表は仮定値のまま。実測方法の決定が要る。
4. **E4 の発生区間**: 旋回と曲げを同時に行う現行方式を維持するか、分離して保持リスクを下げるか（§4.4）。
5. **不適合品の扱い**: E2・E3 のエスカレーション後、製品をどこへ流すか。⑨電気検査・⑩外観検査が対象外であるため、OP030 内での判定が要る。
6. 排出シュートの位置と形状（採用は決定済、詳細は未定）。
