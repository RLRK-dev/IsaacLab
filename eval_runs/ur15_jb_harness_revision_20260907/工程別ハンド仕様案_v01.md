# 工程別ハンド仕様案 v0.1

2026-09-13。実行担当が、ユーザー指定のハンド先行検討を具体化した比較案。
**第一候補は、A＝2本指の専用輪郭、B＝各腕に2本指の丸底溝。3本指・4本指は追加する役割を定めて比較する。**

## 1. 今回決める対象

対象部品の把持面、指先形状、指の本数・配置、駆動方式、開放方向を先に決める。
工程番号は対応を議論するための呼称で、旧部品がAmpere製品にも存在することを意味しない。

| 作業・役割 | 第一候補の手先 | 指／駆動 | 腕数との対応 |
| --- | --- | --- | --- |
| A：部品を置き、締結中に保持 | 交換式の専用輪郭パッド＋荷重を受ける面 | 2本指。既存2Fを使う場合は開閉1駆動 | 保持用1腕＋常設締付工具1腕を比較の出発点にする |
| B：柔軟な配線の両端を保持して配置 | 被覆用の丸底溝。端末姿勢が必要な箇所には別の輪郭受け | 各腕2本指を第一候補。G4は局所2組の保持が必要な場合 | 双腕を比較。S字形成が成立済みとはしない |
| C：位置の決まった端子を締結 | アーム常設の専用締付工具 | フィンガなし | 既存の大小同時締結は2工具。単腕化は順次締結との別比較 |
| 剛体バスバーの配置 | 電気接点・締結穴を避ける専用輪郭 | 2本指 | 単腕候補。締結中の保持要否を部品ごとに対応付ける |
| 外部コネクター嵌合 | ハウジングの輪郭＋肩受け | 2本指。独立した第3接触が必要ならG3 | 単腕候補。線材支持やロック操作が同時に必要かを区別 |
| 筐体・蓋・小部品の搬送 | 対象の輪郭に合うパッドと受け面 | 2本指を第一候補 | 単腕候補。全幅を2F-85で挟めるとは仮定しない |

3STで別のワークを並行処理する方針は維持する。ステーション数・腕数・指の本数は別項目。
第三の腕は、両端保持に加えて中間部を独立に操作するなど、第三の同時作業が必要になった場合の比較候補に留める。

## 2. 公開実物との対応を先に分ける

採用された参照範囲は[Ampere EV HVJB-5-400の公開回路・主要構成](https://help.ampereev.com/hc/en-us/articles/31292470232087-High-Voltage-Junction-Box-HVJB-5-400)。
公開資料で確認できたのは主接触器、プリチャージ・放電のリレーと抵抗、主ヒューズ、補機ヒューズなどで、内部の全型式・把持可能部の製造寸法は未公開／未取得。

- **金属バスバーと柔軟な配線を別の対象にする。** 公式データシートはニッケルめっき銅バスバーを記載し、内部写真にも金属導体と橙色配線が写っている。旧BのU字・S字2本を、実物の必須配線にそのまま割り当てない。
- 主接触器の丸い外観だけで、3本指の120°配置を選ばない。提供されたG3は1対2配置。非通電部の本体・取付部を把持候補として整理し、電気接点・薄い制御配線を避ける。
- 端子の接点座・穴、圧着部、熱収縮部、被覆は役割が違う。写真だけで熱収縮部を荷重支持面に指定しない。
- 外形図の **276.35 mmと133.35 mmは取付穴の中心ピッチ**。筐体幅・内寸として指先寸法に流用しない。

## 3. A：2本指の専用輪郭を第一候補にする

| 設計欄 | 具体化する内容 |
| --- | --- |
| 位置を決める面 | 本体側面または取付部のうち、荷重を受けられる非電気接点の輪郭。片側を基準受け、対向側を押さえとして役割を分ける |
| 指先形状 | 交換式の浅い輪郭ポケット。把持面の段差・肩を受ける形を候補とし、締付穴や端子上面を覆わない |
| 回転の拘束 | 円形面だけで軸回りの向きが決まるとはしない。使える平面・段差を部品側で特定する |
| 荷重を伝える面 | 搬送時と締結中で荷重方向を分ける。使える肩受けがあれば利用するが、締結の反力を無条件に指で受けるとはしない |
| 工具の通り道 | ボルト穴から工具軸方向へ、ビット・ソケット・工具胴の通過域を確保する。旧Aで指と工具が交差した箇所を、そのまま継承しない |
| 取り外し | 着座・締結後に側方へ開き、穴・周辺配線から抜ける形にする。部品の下へ差し込む受けは、着座後に挟まれない構成だけを比較する |
| 柔らかさ | 基準を作る面と薄い交換パッドの役割を分離。全接触面を厚い軟質材にして位置が決まるとは扱わない |

**G3を比較する理由**は、2本指では独立した位置決め・押さえ・開放の役割を両立できない場合。
1本を押さえ、反対側2本を別の接触位置に置く案を比較する。3接触があるだけで六自由度すべてが拘束されるわけではない。

既存2F機構と交換指先を先に検討する。G3へ変更すると独立3駆動・受動3関節になり、既存の開閉1値の制御をそのまま使えない。
締付工具はユーザー指定どおり腕へ常設し、フィンガで工具を握らせない。

## 4. B：被覆保持と端末の姿勢決めを分ける

### B-1. 丸底溝の2本指

第一候補は、各腕の対向指に交換式の丸底溝パッドを設ける構成。
被覆を局所的に支え、端部近くの把持姿勢を対応付ける。ケーブル用の溝は長手方向へ通す。

| 設計欄 | 具体化する内容 |
| --- | --- |
| 把持区間 | 被覆の直線に近い区間を候補にする。被覆端・圧着部の段差・曲がり始めとの位置関係を記録 |
| 断面 | 対向する開いた丸底溝。接触範囲・開口は実線材の外径と許容変形に対応させる。閉じれば被覆を潰す寸法には決めない |
| 長手方向 | 支持長を必要な把持域内に収め、入口・出口の縁を丸める。長くすればよいとはしない |
| 力・滑り | 固定して運ぶ把持と、線を送る案内を別の状態にする。被覆の許容圧・張力が未取得のため、把持力をまだ数値指定しない |
| 開放 | 着座後、対向指をケーブルから離れる方向へ開く。曲がった線や端子に爪が引っ掛からず抜ける断面にする |

### B-2. 端末姿勢を決める必要がある場合

丸底溝だけでは端子穴の向きを一意に決められないため、**荷重を受けられる端末部の輪郭受け**を別に定義する。
接点面・締付穴を空け、着座や締付工具に干渉しない位置で姿勢を決める。
圧着筒・熱収縮部を強く挟めるとは仮定しない。どの面を受けられるかが決まるまでは、端末用ポケットの加工寸法を確定しない。

一体の交換指先で「端末の姿勢決め＋隣接被覆の支持」を担う案と、G4の2組で役割を分ける案を比較する。
前者は接触箇所が増えても指の本数は2本、開閉駆動は1つである。

### B-3. G4を追加するなら役割を明記する

| 保持組 | 役割の比較例 | 別に必要な確認 |
| --- | --- | --- |
| 端末側の1組 | 輪郭を使った端末の位置・向きの保持 | 使える非接点面、工具アクセス、開放空間 |
| 被覆側の1組 | 被覆を支え、端末付近の姿勢や荷重を補助 | 支持長、圧力、滑り、曲がり始めとの関係 |
| 一方だけ開く状態 | 開く組を退避させ、残る組で支持する比較 | 残る組の荷重・モーメント。独立駆動があるだけでは保持保証にならない |

提供仕様の30 mmは2組の**取付間隔**で、運転中に伸縮する長手軸ではない。
末節の受動Y回転は長手軸Yまわりの回転であり、平面S字の接線に合わせて各溝を独立に首振りする軸ではない。
4本指にしただけでケーブル中央部まで狙った形状になるとはしない。

## 5. 旧Bを使った寸法上の注意

旧v06のB bankを変更せずに読んだ局所観測。新版Ampere配線の寸法指定ではない。

旧把持中心は被覆端から30 mm。比較用パッドの長手幅を受領G3/G4案の12 mmとすると、直線上の2F中央配置は24〜36 mm、G3/G4の外側接触域は9〜21 mmと39〜51 mmになる。
この2Fの12 mmは比較の仮定であり、Robotiq標準パッドの寸法ではない。

旧H03-2のJ1側では平面曲がり始めまでの3D弧長が約42.506 mmで、G4の遠い組が曲がり始めに掛かる配置になる。
固定Y座標で計算し直すと、その組の中心で接線方向差は約2.25°、外端で約6.75°。
受動Y回転の±15°とは回転軸が異なるので、「15°以内だから追従できる」とは判断できない。

[数値・入力SHA・再現方法](analysis/hand_contact_span_v01.md)を別紙に記録した。
指先の接触計算、柔らかいパッドの変形、把持力、実際のS字形成はこの観測に含めない。

旧BはH03-1がU字状、H03-2がS字状。指定中心線から手先を求める動画生成であり、端点の力から線材変形を求めるモデルではない。
実際の曲げ・ねじれ・滑り・解放後の戻りの成立は未確認。撤去済みの押さえ2基を自動で復活させる案でもない。

## 7. アーム動作へ渡す前の選定票

各対象について以下を一組として揃える。新しい受入閾値や試験回数は本書で設定しない。

1. 対象部品ID・版・供給姿勢と、触れてよい面／避ける面。
2. 指の本数・配置・駆動数と、交換指先の図。G3/G4採用時は追加指の役割。
3. 把持点・溝／ポケット寸法・材料。未公開値は推定か未確定かを明示。
4. 締結・挿入時の工具通過域と、着座後に開いて抜ける方向。
5. 対象物の許容荷重とハンド能力の根拠。形状確認で代用しない。
6. 手先TCP、質量・慣性、カメラとの関係、腕数の対応。

その後に、Aの締結完了後の両腕同時上昇、Bの両腕同時把持・設置後同時上昇、ボルトの先行取得を軌道へ反映する。
Cの同時締結を単腕化する場合は、ユーザーが指定した同時性との変更点を明示する。
OP020の最新v11は設備による空トレー返却であり、旧両腕トレー返却を双腕必須の根拠にしない。

## 8. 再利用・根拠・今回の成果物

既存のRobotiq 2F-85モデルは開閉1駆動と連動リンクを持つ。
[公式資料の専用指先・力／モーメント制限](https://assets.robotiq.com/website-assets/support_documents/document/online/2F-85_2F-140_TM_InstructionManual_HTML5_20190503.zip/2F-85_2F-140_TM_InstructionManual_HTML5/Content/6.%20Specifications.htm)を参照し、機構を再利用して交換指先を検討する。
G3/G4は独立駆動を追加する新規機構であり、指先交換と同じ変更規模ではない。

参考研究は、[方向別の柔軟性](https://arxiv.org/abs/2307.15589)、[触覚によるケーブル操作](https://arxiv.org/abs/1910.02860)、[端点位置と接線を扱う弾性線状物の形状制御](https://arxiv.org/html/2502.07509v1)。
これらの性能や適用条件を今回の線材・手先の成立証拠として転用しない。

今回作成したのは仕様案、操作できる概念図、旧形状を用いた数値観測。
2F/G3/G4の最終採用、製作寸法、物理成立は未確定。アーム軌道・新規動画・v06原本は変更していない。
設計の採用判断はRs、正式な物理妥当性判定はVaultProtocol V12の独立レビュー経路による。
