Japanese (phase / 動作 / 対象 / 条件 / 振幅等) → machinery regenerates or re-parameterizes the
route → unchanged rows PROVE byte-identity, changed rows pass per-row gates (video leg / OG /
existing verdict machinery) → landed. Deliverable = options + recommendation (方式決定 = Rs 専権).

S-3 **Architecture options (compare at least these 3):**
    (a) TABLE→PARAMS: route code stays hand-written; the table drives a validated parameter layer

        must be redesigned (what does Rs-LOCK mean for generated code?).

        library. Cleanest teaching loop; biggest build + re-verification of ALL banked behavior.

    migration cost, verification story (byte-identity semantics per option), governance/L-triage of
