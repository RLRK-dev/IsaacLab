### R3-01（HIGH）INTER_ARM 項の評価意味論が裁定条件 ⑤ と §3.7 / T-37 に反し、同時運動する両腕に対して non-conservative

- 再現（本文の語のまま）: 両腕 setpoint L0 / R0（十分離れている）。1 policy step の提案 = L0→L1、R0→R1 で、2 線分は途中で交差するが、L1 は R0 から遠く、R1 は L0 から遠い。05:457 の規則で arm L の command を評価: 線分 L0L1 × R の snapshot 状態（点 R0）→ min separation 充足 → admit。次に arm R: 線分 R0R1 × L の「直近 admitted setpoint」（点 L1）→ 充足 → admit。実機は両腕が同時に線分上を進み中点付近で衝突する。両評価とも他 arm を**点**に固定しており swept-volume の交差を見ていない。05:291 / T-37 は「両 arm の提案線分」の対で書かれており、05:457 と食い違う。06:321 の `cmd.resource`（1 command = 1 arm）モデルでも、05:496-503 の `GatewayCommand`（arm field 無し・1 payload）でも同じ結論。
